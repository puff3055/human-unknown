## 你可以给每个 UFO 事件自动做一次「验尸」

比如一个人报告：

> 2004 年 8 月 17 日 22:43  
> 我看到天空中一个巨大的发光球快速划过。

网站不要只告诉我：

**“有人看见 UFO。”**

它可以同时去查：

**NASA CNEOS 火流星数据**  
→ 当晚这个区域有没有火流星。CNEOS 有时间、经纬度、高度、速度、能量，而且有机器可读数据。([cneos.jpl.nasa.gov](https://cneos.jpl.nasa.gov/fireballs/?utm_source=chatgpt.com))

**CelesTrak 卫星轨道数据**  
→ 当时有没有 ISS、Starlink 或其他卫星经过。它现在可以直接返回 CSV / JSON / TLE。([celestrak.org](https://www.celestrak.org/NORAD/documentation/gp-data-formats.php?utm_source=chatgpt.com))

再叠加：

天气 / 云量 / 能见度  
飞机航迹  
月亮和金星位置  
火箭发射  
气象气球

于是每一个事件都有一张：

### 👽 CASE 00291

**目击报告**

三角形物体  
静止 12 分钟  
无声音  
3 名目击者

**证据**

🟢 原始政府文件  
🟢 目击证词  
🟡 照片  
⚪ 无雷达记录

**环境核对**

✕ 非火流星  
✕ 未发现匹配飞机  
? 有一颗卫星经过，但轨迹不匹配  
✓ 当晚晴朗

**官方结论**

UNRESOLVED

这就会比普通「世界十大 UFO 事件」网站好玩太多。

### 至于「不同的外星人」，我会这样建数据

不要找一个所谓“Alien Dataset”，基本没有靠谱的。

直接自己建立一张 **实体谱系表**：

**Grey / 灰人**  
Small Grey / Tall Grey  
Nordic / 北欧型人形实体  
Reptilian / 爬虫型  
Mantid / 昆虫型  
Robotic Entity / 机械型  
Hairy Humanoid / 毛发人形  
Luminous Being / 发光实体  
等等。

每个实体不写：

> 「这个外星人生活在……」

而写：

> **最早什么时候被描述？**  
> **哪些事件中有人声称见过？**  
> **不同年代外貌有没有变化？**  
> **这种形象什么时候进入大众文化？**  
> **有多少独立事件报告类似形态？**

这样甚至可以出现一个我觉得非常好玩的东西：

## 👽 外星人进化树

不是生物进化。

是：

**「人类描述的外星人，是怎么进化的？」**

1940s 飞碟  
↓  
1950s 金发人形外星人  
↓  
1960s–70s 小灰人  
↓  
1980s 大眼灰人越来越标准化  
↓  
1990s 爬虫人叙事兴起

然后把**电影上映、新闻事件、著名 UFO 案件、目击报告数量**叠在同一条时间线上。

你甚至能研究：

> **究竟是人类越来越多地遇见同一种“外星人”，还是大众文化逐渐教会人们外星人“应该长什么样”？**

这个网站一下就不只是 UFO 百科了。

# 但科幻作品给出的，是另一套完全不同的谱系

科幻史里其实反复出现几种非常不同的“智慧模型”。《科幻百科全书》甚至专门指出，很多作品嘴上说外星智慧非常不同，真正试图表现“另一种智能究竟如何运作”的作品反而很少。([sf-encyclopedia.com](https://sf-encyclopedia.com/entry/intelligence?utm_source=chatgpt.com))

我把大量作品收束以后，会得到大概这样的谱系：

| 非人类认知 | 代表想象 | 它挑战人类什么默认值 |
|---|---|---|
| **同时性时间** | 《降临》/《你一生的故事》 | 时间为什么一定从过去流向未来？ |
| **行星意识** | 《索拉里斯》 | 一个“人”为什么一定要有身体和边界？ |
| **群体意识** | *Star Maker*、各种 Hive Mind 作品 | “我”为什么一定是智慧的最小单位？ |
| **异语言文明** | *Embassytown*、《降临》 | 语言只是表达思想的吗，还是语言决定什么东西能够被想？ |
| **遗迹 / 无交流文明** | 《路边野餐》、*Rendezvous with Rama*、2001 | 对方为什么一定想和我们说话？我们甚至可能只是捡到了它留下的垃圾。 |
| **异感官文明** | *Star Maker* 等 | 为什么视觉、听觉才是理解世界的主要方式？ |
| **世界级 / 生态级智慧** | 《索拉里斯》、Le Guin 的相关作品 | 智慧为什么一定属于某一个生物？ |
| **多现实 / 非唯一世界** | 《彗星来的那一夜》以及大量平行世界作品 | 为什么世界只能有一个版本？ |

《降临》最特别的地方就在于，它没有只给外星人换个长相，而是让一种语言带来**非顺序的时间感知**。([sf-encyclopedia.com](https://sf-encyclopedia.com/entry/arrival?utm_source=chatgpt.com))

《索拉里斯》更极端：那个非人类智慧可能就是整个海洋/星球，人类甚至无法确定它做出的行为究竟算不算“交流”。([sf-encyclopedia.com](https://sf-encyclopedia.com/entry/communications?utm_source=chatgpt.com))

*Embassytown* 里则出现了一种极奇怪的语言结构：外星语言必须由两个声音同时发出，而且它们原本无法说出虚假陈述。([sf-encyclopedia.com](https://sf-encyclopedia.com/entry/mieville_china?utm_source=chatgpt.com))

《路边野餐》甚至把“接触”彻底拿掉了：外星文明可能来过，但没人见过它们，它们只留下了一堆人类无法理解的东西，就像人类野餐后遗留的垃圾一样。([sf-encyclopedia.com](https://sf-encyclopedia.com/entry/aliens?utm_source=chatgpt.com))

而 Hive Mind 这一支非常古老：科幻长期在想象一种“整体才是一个心智、个体只是组成部分”的智慧。([sf-encyclopedia.com](https://sf-encyclopedia.com/entry/hive_minds?utm_source=chatgpt.com))

所以你的题材其实比“外星人”还大。

《使馆城》（*Embassytown*，《使馆城》）里的异星语言必须由两个声音同时发出，这些生物原本甚至没有“说谎”这种能力。这里不是单纯造了一套外星语，而是连“什么能够成为意义”都改变了。([sf-encyclopedia.com](https://sf-encyclopedia.com/entry/mieville_china?utm_source=chatgpt.com))

《时间之子》（*Children of Time*，《时间之子》）则从蜘蛛一路发展出自己的文明、技术和知识系统，甚至使用蚂蚁作为技术体系的一部分；作品最后也没有停留在人类与异种互相消灭，而是走向沟通与合作。([panmacmillan.com](https://www.panmacmillan.com/blogs/science-fiction-and-fantasy/children-of-time-recap?utm_source=chatgpt.com))

还有《荒野机器人赞歌》（*A Psalm for the Wild-Built*，《荒野机器人赞歌》）——严格来说不属于外星人，但非常适合你所谓的“非人类文明”：机器人觉醒之后集体停止劳动、离开人类社会进入荒野，几百年以后回来问人的问题居然是“人到底需要什么？”([us.macmillan.com](https://us.macmillan.com/books/9781250236210/apsalmforthewildbuilt/?utm_source=chatgpt.com))

所以现在我反而会有意识地把“三体式战争、征服、文明博弈”放到很低优先级。不是说这类科幻不存在价值，而是对**你的作品目的**来说，它们往往还是把国家、军队、资源竞争、敌我关系放大到宇宙里。你现在要找的是那些真正对“一个文明还可以怎样存在”动过手术的作品。

## 第一轮调研后，我觉得 HUMAN UNKNOWN 有 8 条「向外的边」

它们不是网站菜单，也不是科普分类。

这是我们创作者自己手里的地图：**人类目前习以为常的哪些规则，科幻曾经尝试把它推翻？**

| 想象力的边 | 人类默认规则开始失效 | 很好的样本 |
|---|---|---|
| **时间 / 尺度** | 大家活在差不多的速度里；时间向前 | 《龙蛋》（Dragon's Egg）、《降临》（Arrival）、《爱，死亡和机器人：冰河时代》（Love, Death & Robots: Ice Age）、《星际拓荒》（Outer Wilds） |
| **“我”的边界** | 一个身体里住着一个我，一生都是同一个我 | 《造星主》（Star Maker）的共生与群体心智、《时间之子》（Children of Time）系列 |
| **生命的边界** | 生命应该是一个个会动的生物 | 《索拉里斯》（Solaris）、《共生》（Semiosis）、《阿凡达》（Avatar）、《拾荒者统治》（Scavengers Reign） |
| **意识载体** | 意识应该住在有机大脑里 | 《万神殿》（Pantheon）的上传意识、《散居》（Diaspora）的数字生命、《爱，死亡和机器人：齐马蓝》（Zima Blue）、《荒野机器人赞歌》（A Psalm for the Wild-Built） |
| **交流 / 意义** | 沟通就是语言，你说一句我答一句 | 《使馆城》（Embassytown）、《降临》、《索拉里斯》、《路边野餐》（Roadside Picnic） |
| **现实结构** | 世界只有一个版本，规则稳定 | 《彗星来的那一夜》（Coherence）、《瞬息全宇宙》（Everything Everywhere All at Once）、各种不同物理法则的 Alternate Cosmos 想象 |
| **文明 / 价值** | 文明要发展、生产、进步、占有、竞争 | 《荒野机器人赞歌》、《一无所有》（The Dispossessed）、《造星主》等 |
| **观察者尺度** | “我”永远站在人类尺度看世界 | 游戏《万物》（Everything）：可以成为动物、原子、星球甚至星系，从不同存在的位置看同一个宇宙 |

这里面很多作品会同时落在几条边上，这反而是对的。比如《阿凡达》里的 Eywa 不是简单的“外星生态”：记忆可以存储于自然神经网络，Na'vi 可以通过连接访问祖先与生态记忆，所以它同时碰到了**生命、意识、自我、文明**几个方向。([avatar.com](https://www.avatar.com/pandorapedia/the-tree-of-voices?utm_source=chatgpt.com))

《造星主》尤其值得进你的 HUMAN ARCHIVE。它在 1937 年就一路想象不同感官价值、共生物种、群体心智、活着的世界乃至宇宙尺度意识，几乎就是一本早期的“人类想象力边界地图”。([sf-encyclopedia.com](https://sf-encyclopedia.com/entry/stapledon_olaf?utm_source=chatgpt.com))

## 硅基意识当然属于 HUMAN UNKNOWN

而且我现在觉得，它不能只是旁支。

因为外星生命仍然容易让人产生一种想法：

> “只是另一个星球上的生物。”

但数字意识直接把**“生命一定需要身体吗？”**这个基本经验抽走了。

《万神殿》（Pantheon）把人类意识上传成 Uploaded Intelligence；《散居》（Diaspora）甚至从一个 AI 在数字环境中的“出生”开始；《排列之城》（Permutation City）继续推到“一个意识可以复制成多个同时存在的版本”。([amc.com](https://www.amc.com/blogs/amc-greenlights-first-ever-prime-time-animated-series-pantheon--1004029?utm_source=chatgpt.com))

而《荒野机器人赞歌》更符合你的审美：机器人获得自我意识以后，没有走“统治人类”的老路，而是**放下工具、离开生产体系、进入荒野**，后来回来询问“人到底需要什么”。这种世界观对 HUMAN UNKNOWN 的价值比“AI 毁灭人类”大得多。([us.macmillan.com](https://us.macmillan.com/books/9781250807748/apsalmforthewildbuilt/?utm_source=chatgpt.com))

所以我们可以明确过滤掉一大堆：

**战争、征服、灭绝、黑暗森林、谁比谁厉害。**

不是因为不能有冲突，而是这些东西经常只是把人类已经玩了几千年的权力游戏复制到宇宙里，对我们要找的“认知边界”贡献很有限。

# 调研以后，我现在留下 8 个「世界种子」

这才是之后可能真正变成 HUMAN UNKNOWN 里面某个 SIGNAL 的东西。

| 世界种子 | 用户进去最先感觉到什么 | 为什么值得继续 |
|---|---|---|
| **极速文明** | 你停留几十秒，它已经经历几百年 | 时间直接成为视觉和交互，不需要解释 |
| **活着的世界** | 一开始以为是环境，后来发现整个环境就是生命 | 极强视觉；完全摆脱聊天框 |
| **可分叉的硅基意识** | “你”可以复制、暂停、迁移、同时存在 | 网页 UI 本身可以表现意识结构 |
| **无单数文明** | 一群身体组合起来才是一个存在，组合变化，“我”也变化 | 真正冲击人类对个体的默认理解 |
| **不可翻译文明** | 你无法直接说话，必须慢慢发现这里怎样产生“意义” | 交互可以非常新 |
| **遗迹文明** | 谁都不在，只剩一些完全不知道用途的东西 | 纯探索；未知感极强 |
| **多现实世界** | 你的操作不断制造不同版本的网页/世界 | 网页媒介本身就是多重现实 |
| **后劳动文明** | 这里没有任务、成绩、进度条，甚至不理解“效率” | 它不是教你放松，而是整个文明根本不用这套价值系统 |

其中“遗迹文明”来自一个我觉得很值得你的作品吸收的科幻传统：《路边野餐》把所谓外星接触想成“对方只是来过，留下了一堆我们完全不理解的东西”，人类像在捡野餐者留下的垃圾。([sf-encyclopedia.com](https://sf-encyclopedia.com/entry/zone?utm_source=chatgpt.com))

而《使馆城》给我们的启发也不应该是复制它的外星语言，而是：**如果一种语言必须同时由两个声音共同产生，而且原本无法表达虚假，那么“输入框”这种交互本身就已经不成立了。**([sf-encyclopedia.com](https://sf-encyclopedia.com/entry/mieville_china?utm_source=chatgpt.com))

它最值得借的不是时间循环，而是：

**探索本身就是进度。**

追踪信号、发现一个地方、理解遗迹、获得新的认知，然后因为“我现在知道了一件事”，下一次我就能走得更深。官方对它的描述本身就是一个不断变化的太阳系，通过追踪信号、破解遗迹来探索未知。([mobiusdigitalgames.com](https://www.mobiusdigitalgames.com/games.html?utm_source=chatgpt.com))

**我刚才还不知道自己在看什么。

再后来我发现它记得我。  
最后我才发现，我一直站在这个文明的“记忆”里面。**

这才叫“接触加深”。

# 一、我们现在其实有两层「8」

前面一度是 6 条边界，后来加入硅基意识、观察尺度等之后，我把它扩成了 **8 条人类想象力边界**。

它是后台研究框架：

| 人类默认规则的边界 | 对应目前的一个世界种子 |
|---|---|
| 时间 / 尺度 | **极速文明** |
| 生命 | **活着的世界** |
| 意识载体 | **硅基意识** |
| “我”的边界 | **无单数文明** |
| 交流 / 意义 | **不可翻译文明** |
| 未知 / 理解 | **遗迹文明** |
| 现实结构 | **多现实世界** |
| 文明 / 价值 | **后劳动文明** |

这张表不是网站导航。

用户永远不需要看到：

> 「请选择时间边界、生命边界……」

这些只是我们用来确保 **8 个世界真的在探索不同的地方，而不是换 8 套皮肤。**

然后前面我又从这 8 条边界里，各抽出了一个比较有潜力变成交互的**世界种子**。

所以现在第二阶段真正该做的，就是：

# 二、所有世界共用一个隐藏结构

这个我现在觉得可以正式锁死。

首页：

**发现 → 被吸引 → 捕获信号**

进入某个 SIGNAL：

**靠近 → 进入 → 初步感知 → 发生接触 → 更深一层 → 离开**

注意，这些词不一定显示出来。

它们只是幕后结构。

比如「极速文明」的深入方式是时间过去。

「活着的世界」的深入方式是环境逐渐记住你。

「不可翻译文明」的深入方式是你逐渐学会一点点“怎么和这里发生意义”。

所以看起来完全不一样。

这很好。

再几秒：

城市。

再几秒：

战争留下的遗迹被新的建筑覆盖。

再过十秒：

刚才的建筑已经变成考古遗址。

用户甚至什么都不用干。

**看，就是交互。**

### 接触

这里我会设计一个非常简单但很有意思的动作：

用户可以向下面的世界投下一次**信号**。

一个声音、一个光点、一句话都可以。

你发出去。

没有立即回复。

文明继续快速演化。

几十代以后，某个时代突然出现和你的信号有关的符号。

他们可能把它理解成：

神话。

天文现象。

数学。

警告。

艺术。

你才发现：

> **你刚才的一秒，在他们那里变成了几百年的历史。**

### 深入

继续观察。

你曾经发出的东西可能完全变形。

它已经不属于你了。

### 这个世界最重要的 UI

几乎没有。

只需要：

**世界本身 + 极少量时间提示 + 投递一次信号。**

甚至不要传统时间轴。

时间就是画面本身。

# 02｜活着的世界

**人类规则被替换：**

> “文明生活在环境里面。”

这里是：

> **环境就是文明。**

### 第一眼

SIGNAL 204 甚至不像信号。

首页某一块黑暗区域，鼠标靠近以后，它才微微收缩。

像是在注意你。

### 靠近

越靠近：

根系亮起来。

水发生流动。

孢子改变方向。

### 进入

完全没有角色。

没有“欢迎来到 XX 星球”。

没有聊天框。

你只是出现在这里。

### 最核心交互

**停留。**

鼠标停在哪里久一点：

那个区域慢慢改变。

你走开以后，它没有恢复。

再次回来：

那里还留下你经过的痕迹。

于是用户自己发现：

> 它记得我。

继续探索以后，甚至会出现更奇怪的事情：

第一次：你靠近 → 它反应。

第二次：你靠近 → 它提前反应。

第三次：**你还没有过去，它已经开始变化。**

这时候才会有一种很强的：

> 它在认识我。

### 接触

如果用户真的想试着说一句话，也可以。

但文字进入这里以后不会得到文字回复。

例如：

> “你好。”

字消失。

变成一串波纹。

波纹进入地面。

几十秒以后，远处开出一片从来没有出现过的结构。

这才是这个文明的“回答”。

# 03｜硅基意识

我觉得这个世界上一版视觉虽然漂亮，但**仍然太像 AI 控制台**。

下一版应该彻底换。

**人类规则被替换：**

> 一个意识一生只有一个版本。

### 第一眼

一个东西。

一个极简单的意识。

用户碰它。

它突然变成两个。

### 然后最奇怪的事情发生

两个都认为：

> **我是原来的那个。**

没有：

`COPY 01`
`COPY 02`

这种软件感。

视觉上它们看起来甚至完全一样。

### 进入

用户跟其中一个发生一点交互。

另一个不知道。

于是它们开始不同。

继续：

复制一个。

暂停一个。

让两个合并。

### 接触

你可能问：

> “你是谁？”

三个版本会给出三个不同回应。

但它们全部拥有同一个“出生前记忆”。

用户真正体验的不是 AI 聊天。

而是：

> **当我可以被完美复制以后，到底哪个还是我？**

### 最有趣的一步

用户离开其中一个版本。

后来再回来。

它说：

> “你终于回来了。”

但用户根本不知道：

**自己之前见的是不是这个版本。**

这就开始有一点真正的陌生感了。

# 04｜无单数文明

我越来越觉得这个世界其实很好，只是名字现在比较研究感，后面可以重新命名。

**人类规则被替换：**

> 一个身体 = 一个存在。

这里：

> **很多生命暂时组成一个“人”。**

### 第一眼

一大群微小东西。

用户自然会认为：

> 好多生物。

### 进入之后才发现

七个聚在一起。

突然形成某种稳定结构。

出现一个声音。

它说：

> “你好。”

过一会儿，其中两个离开。

声音、性格、记忆开始改变。

另外三个加入。

这个“存在”又变了。

### 核心交互

用户可以用鼠标：

**聚拢 / 分离 / 连接。**

不是拖拽菜单。

就是直接操作这些生命。

不同组合：

形成不同意识。

### 更深层

你甚至可以发现：

这里不存在：

“分手”

“死亡”

“永远是我”

这种概念的对应物。

可能只有：

**组成。**

**分散。**

**再次组成。**

于是很多人类经验会自然显得很奇怪。

而我们完全不用做哲学讲解。

# 05｜不可翻译文明

这个我觉得是 **最值得挑战“新交互”奖的世界之一。**

**人类规则被替换：**

> 沟通 = 语言。

### 捕获

这个信号根本不是文字。

是：

一个声音。

一种颜色变化。

一段重复运动。

### 进入

屏幕上没有：

> “请输入你的问题。”

甚至一开始用户不知道怎么交流。

她动鼠标。

它回应了一种颜色。

她点一下。

它发出两个音。

连点三下。

对面的东西突然发生一次更复杂的变化。

### 核心玩法

用户慢慢试。

像第一次和一种完全不同的动物建立关系。

你逐渐发现：

某个节奏 ≈ 靠近。

某个方向 ≈ 我知道你在那里。

某种长按 ≈ 交换。

但永远不要给一张：

> 「外星语言翻译表」

那一下体验就死了。

### 接触

玩了一分钟以后，用户第一次成功表达出一个非常简单的意思。

可能只是：

> **我在这里。**

对方回应。

那个瞬间会非常强。

因为这是用户自己“学会”的。

# 06｜遗迹文明

这个世界和其他世界完全不同。

**这里甚至没有接触对象。**

### 捕获

首页发现一个非常弱的信号。

甚至系统提示：

> SIGNAL LOST

但那里还有一样东西。

### 进入

一片空旷世界。

文明早已经不在。

只有几个物体。

不知道：

工具？

玩具？

尸体？

艺术？

通讯器？

垃圾？

### 核心交互

完全不给说明。

摸。

旋转。

组合。

等待。

放下。

改变顺序。

### 最关键的是

每一次反应都让你更加迷惑，而不是逐渐变成一道谜题。

例如：

一个东西你碰它没有反应。

你走开以后，它自己移动。

再去碰，它又不动。

后来你发现：

**它可能只有在没有被观察时才工作。**

但网站永远不告诉你是不是。

### 这个世界的感觉应该是

> 我已经走到了人类理解能力的边缘。

而不是：

> 我解开了外星机关。

这是非常重要的区别。

# 07｜多现实世界

这个我觉得特别适合网页媒介。

因为：

# 网页本身可以裂开。

**人类规则被替换：**

> 每次事情发生，都只有一个结果。

### 开始

用户看到一个很正常的世界。

点击一个东西。

页面轻微闪一下。

继续探索。

她会开始发现：

左边有一个东西，她之前明明移动过。

现在居然又回到了原位。

### 再深入

她才发现：

刚才点击的时候：

**网站已经复制出了另一个现实。**

现在两个现实在重叠。

### 核心交互

每一次有意义的操作：

都会产生世界分支。

但不要出现传统游戏：

> A / B 请选择。

用户甚至不知道自己什么时候做出了选择。

后来可能看到：

另一个版本的鼠标。

另一个版本的自己曾经留下的动作。

### 接触

最漂亮的一个场景可以是：

两个现实暂时重叠。

用户可以把其中一件东西从现实 A 拖进现实 B。

产生一个：

**本来不应该存在的东西。**

这特别适合数字艺术。

# 08｜后劳动文明

这个是八个里面最不“宇宙奇观”的。

但它可能是**最能重新看自己的一个世界。**

**人类规则被替换：**

> 文明 = 发展、生产、进度、效率。

### 最开始，它甚至有点烦人

你进来。

什么都没有要求你做。

没有任务。

没有倒计时。

没有红点。

没有奖励。

用户开始到处点。

什么都不发生。

### 真正的入口

当用户终于停下来。

世界开始自己发生事情。

一群生命出现。

做一些看起来“没有意义”的事情。

排列石头。

等待一种风。

看某种东西长大。

拆掉刚刚做好的东西。

### 接触

你问：

> “你们每天做什么？”

它们甚至可能无法理解：

> “每天为什么必须做什么？”

### 最重要的点

这个世界千万不要变成：

> “疗愈你，教你不要卷。”

那就特别土。

它应该真的拥有一个完整价值系统。

例如：

人类以“完成”为价值。

它们可能以：

**维持。**

**循环。**

**变化。**

**观察。**

作为文明价值。

所以它们不是来教育人类。

只是：

> **完全不 care 我们的那套坐标。**

这个我觉得很符合你刚才说的东西。

# 六、下一步真正需要细化的，是这 5 件事

现在已经不该继续想大概念了。

### 1. 每个世界的 90 秒体验线

精确到：

**第 0 秒看到什么 → 第一次操作 → 第一次异常 → 第一次理解 → 第一次真正接触 → 离开。**

这个是下一步最重要的。

### 2. 每个世界的「唯一核心交互」

严格限制：

**一个世界只能有一个最核心的交互机制。**

例如：

活着的世界 = **停留 / 靠近**

多现实 = **每一次动作都会分叉**

不可翻译 = **试探并建立意义**

其他东西全部服务它。

这样不会又做成乱七八糟的功能网站。

### 3. 每个世界的感官规则

不是 UI 规范。

而是：

**这个世界怎么动？怎么响？什么节奏？什么东西让人靠近？**

尤其你本身就是视觉/感受型，这一层应该非常重要。

### 4. HUMAN ARCHIVE 藏在哪里

体验结束以后才可以看到：

**这个世界来自人类哪些想象。**

电影、小说、游戏、艺术、科学推演。

例如：

《索拉里斯》  
《龙蛋》  
《降临》  
《爱死机》  
《阿凡达》……

这一层可以变成整个作品的深度。

### 5. 首页的真实探索机制

刚才图片还是一个视觉草稿。

真正要回答：

> 三个 SIGNAL 怎么被发现？

是鼠标探索？

声音？

滚动？

信号偶尔出现？

不同用户会不会先捕获不同信号？

**首页不是菜单，所以这一块其实是整个产品最重要的交互之一。**

### 1. 「硅基意识」到底是什么？

我之前这个名字取得不好。

如果把它真的做成体验，最强的一幕应该是：

你先遇见一个意识。

你和它待了 20 秒。

突然，它分成两个。

**两个都说：**

> 我就是刚才和你说话的那个。

右边停在分裂的那一秒。

## 2. 第四个：对，就是「换组合 = 换一个生命」

而且这一个我现在反而觉得**比之前更强**。

因为我后来找到一个几乎完美对应的科幻案例：

### 《深渊上的火》A Fire Upon the Deep

Vernor Vinge 写了一种叫 **Tines** 的生物。

一个“人”并不是一只生物。

而是大约 **4–8 个身体共同组成一个心智**。成员太少，甚至无法组成完整人格；不同 pack 靠得太近还会互相干扰。([wired.com](https://www.wired.com/2022/11/geeks-guide-fire-upon-the-deep/?utm_source=chatgpt.com))

更关键的是：

**某个成员死亡、离开，或者新的成员加入，整个“人”的记忆和人格都会变化。**

所以你刚刚理解得完全对：

> **换了组合，就换了生命。**

这就特别适合网页。

比如屏幕上有：

`● ● ● ● ●`

五个生命组成一个意识。

它正在和你发生互动。

你把其中一个拖出去：

`● ● ● ●      ●`

它突然忘记一部分东西。

语气也变化。

你再让另一个陌生生命加入：

`● ● ● ● ●`

它形成了一个**新的“人”**。

不是旧角色换了皮。

真的已经是另一个生命。

甚至“死亡”在这里也会变得非常奇怪：

一个身体死了，  
**这个人未必死。**

所有身体都还活着，但组合被拆散，  
**这个人反而可能已经不存在了。**

这个我觉得非常 HUMAN UNKNOWN。

# 3. 第 5 个为什么和「活着的世界」不一样？

你这个质疑是对的。

上一版确实写得太像：

> 我做动作 → 对方非语言回应。

所以看上去都是一样的。

我现在会直接把第五个改名。

不要：

**不可翻译文明**

这个名字本身就给人“你就是看不懂”的感觉。

改成：

# **异质语言文明**

两者根本区别应该是：

### 活着的世界

你探索的是：

> **谁在和我发生关系？**

最终发现：

**环境本身就是主体。**

你靠近、水流改变、植物记住你、地貌开始预判你的轨迹。

这里的重点是：

### **生命的边界。**

《索拉里斯》里的海洋可能本身就是智慧；《Semiosis》里人类必须和有智慧的植物建立关系；《阿凡达》的 Eywa 则通过自然神经网络保存和访问记忆。([sf-encyclopedia.com](https://sf-encyclopedia.com/entry/living_worlds?utm_source=chatgpt.com))

---

### 异质语言文明

这里你从一开始就知道：

**有一个东西正在试图跟我沟通。**

问题在于：

它产生“意义”的方法和我们完全不同。

比如它永远同时发出：

**一个形状 + 两个声音 + 一个节奏。**

你乱点不会永远迷惑。

你会慢慢发现稳定规律：

某种节奏总在它靠近之前出现。

某种图形总在它重复你的动作时出现。

经过几轮，你第一次尝试自己组合：

`形状 A + 长音 + 短脉冲`

对方突然停下来。

然后准确地回应。

这时候用户会产生：

> **卧槽，我刚才真的“说”了一句话。**

它的核心不是“对方有反应”。

而是：

# **从没有意义 → 逐渐长出意义。**

《使馆城》（*Embassytown*）就是一个非常好的基础参考：Ariekene 的语言必须由两个声音同时发出，而且其语言结构一开始甚至排除了说谎。([sf-encyclopedia.com](https://sf-encyclopedia.com/entry/mieville_china?utm_source=chatgpt.com))

而 Lem 的《其主之声》（*His Master's Voice*）整个故事就是科学家试图理解来自外部智慧的讯息。([penguinrandomhouse.com](https://www.penguinrandomhouse.com/books/654015/his-masters-voice-by-stanisaw-lem-foreword-by-seth-shostak-translated-by-michael-kandel/?utm_source=chatgpt.com))

所以 2 和 5 我现在认为**可以同时存在**，只要互动机制一定彻底分开：

**2 = 进入一个活着的生态。**  
**5 = 学会一种非人的意义系统。**

# 08｜维度世界

这是我这一轮专门补出来的。

### 《平面国》Flatland

1884 年就写了一个二维文明。

二维居民无法理解三维球体；当一个球穿过二维世界时，他们看到的不是“球”，只会看到：

一个点出现  
→ 圆越来越大  
→ 圆越来越小  
→ 消失。

因为他们只能感知三维物体经过自己世界的**切面**。([penguinrandomhouse.com](https://www.penguinrandomhouse.com/books/124/flatland-by-edwin-a-abbott/?utm_source=chatgpt.com))

这个做网页太适合了。

你进入以后：

整个网站真的突然变成二维规则。

一个奇怪物体进入页面。

你只看见：

`·`

然后：

`○`

然后：

`◯`

然后缩小。

你根本不知道它是什么。

直到你通过某个交互突然获得“高一维视角”：

### 原来刚才有一个巨大东西一直穿过这个世界。

甚至下一层可以反过来：

一个四维东西穿过我们三维世界。

我们也只能看到它不断变化的三维截面。

这个未知不是纯困惑。

它会带来一次非常明确的：

> **原来我看不到，不代表它不存在。**

视觉上也能和另外 7 个完全不同。

# 遗迹文明我也想修正一下

你说不希望体验就是：

> 什么都不知道，好迷惑。

完全同意。

所以遗迹文明不能做成“作者随便搞怪”。

它必须遵守：

### **局部可理解，整体不可穷尽。**

例如用户遇见 3 个遗物。

第一个：

只有在你不看它的时候移动。

用户通过几次试验发现规律。

第二个：

放进去一个东西，会出来另一个东西，但转换关系稳定。

用户开始猜它的规则。

第三个：

你大概摸到规则，但始终无法确认用途。

这样你获得的是：

> **我知道了一点。**

而不是：

> “作者到底想干嘛？”

《路边野餐》很适合这条线：外星访问者没有主动接触，只留下大量性质异常、超出人类物理理解的物质与遗物，人类只能研究和拾取它们。([sf-encyclopedia.com](https://sf-encyclopedia.com/entry/zone?utm_source=chatgpt.com))

声音、运动、整体形态再次瞬间重组。

**组合 = 身份。**

# 所以我现在会给整个项目定一个公式

## 一个世界 = 一条陌生规则 + 一个核心动作 + 一个不可忽略的变化。

这比我们继续写文明设定重要得多。

我甚至重新按这个公式看了一遍现在 8 个世界：

| 世界 | 用户只做什么 | 世界立刻怎样改变 | 用户最后感受到什么 |
|---|---|---|---|
| **极速文明** | **停留不动** | 城市几十秒内经历数代兴衰 | 我的“一会儿”可能是另一个生命的一生 |
| **活着的世界** | **靠近某处** | 环境收缩、发光、留下痕迹，下次甚至提前回应 | 背景其实一直是生命 |
| **无单数文明** | **拖走 / 加入一个生命** | 整体声音、形态、行为瞬间重组 | 换组合，就是换了一个“人” |
| **异质语言文明** | **模仿一个节奏** | 对方第一次给出明显不同的“理解回应” | 我刚刚真的说出了一点东西 |
| **遗迹文明** | **停止触碰 / 移开鼠标** | 遗物反而开始自己活动 | 这个东西遵循的因果和我的直觉不同 |
| **多现实世界** | **点击一次** | 页面出现另一个动作结果留下的幽灵痕迹 | 我刚才制造了另一个现实 |
| **尺度迁移** | **持续缩放 / 滚动** | 细胞→生命→生态→行星→星系，主体不断切换 | “我所在的尺度”只是一个偶然的位置 |
| **维度世界** | **拖动一个截面** | 原本毫无意义的变化突然组成更高维整体 | 我一直只能看到完整世界的一部分 |

这样我就觉得清楚多了。

# 而且你刚才提「声音」，我觉得很值得用

但我不会让整个网站都靠声音。

否则 8 个文明最后又变成同一种交互。

那又变 ChatGPT 了。

用户只需要：

**嗯——嗯、嗯。**

或者敲：

**短、短、长。**

文明用：

光  
形状  
位置  
另一种声音

回应。

用户慢慢发现一个规律。

这时候她第一次主动复制那个规律。

世界突然发生非常明确的回应：

所有东西停下来。

一个结构靠近她。

发回相同节奏。

这一瞬间就是：

没有一个字。

## 声音还可以用得更身体化

你刚刚说：

> 声音越大，界面也发生变化。

这个方向是成立的。

而且技术上比“识别人说了什么”简单很多。

只读取：

**音量 / 持续时间 / 节奏 / 频率变化**

根本不用语音识别，也不用 LLM。

比如某个文明：

轻声 → 它靠近  
突然很响 → 整个结构散开  
持续哼唱 → 不同部分开始同步

用户自己会通过试探理解：

> 它不是在听我“说什么”。  
> **它在感受我的声音作为一种物理存在。**

这个非常 HUMAN UNKNOWN。

# 摄像头，我暂时不建议作为核心

概念上确实很好玩。

比如：

伸手靠近 → 生物靠近你的手  
两个手指合并 → 两个生命融合  
张开手 → 群体散开

视觉冲击会很强。

但黑客松 MVP 有几个现实成本：

浏览器权限  
手势识别  
光线  
摄像头角度  
现场 Demo 稳定性

很容易你花一大堆开发时间，最后真正的文明体验反而没做出来。

所以我的优先级会是：

**鼠标 / 触摸 > 麦克风 > 摄像头。**

鼠标和触摸其实完全可以做得非常“身体”，关键不在设备高级，而在**世界如何回应动作**。

# 我觉得我们现在最重要的，也不是先决定「声音还是鼠标」

因为这是工具。

真正先要决定的是：

> **每个世界，用户只能做一个动作的话，我最希望她做什么？**

然后再反推输入方式。

例如：

**极速文明**  
最重要的是“观察” → 鼠标不动 / 停留。

**活着的世界**  
最重要的是“靠近” → 鼠标距离。

**无单数文明**  
最重要的是“组成” → 拖拽。

**异质语言**  
最重要的是“模仿 / 发出” → 麦克风或节奏点击。

**多现实**  
最重要的是“选择产生分叉” → 普通点击本身。

**尺度迁移**  
最重要的是“尺度改变” → 滚轮。

这样其实很漂亮：

### 每进入一个世界，你连“怎么使用网页”都要重新学。

这就正好兑现：

> **这个网页暂时接管了我理解世界的规则。**

甚至鼠标在一个世界里代表“身体”，在另一个世界代表“观察”，在另一个世界代表“切开维度”。

这已经开始非常有作品感了。

# 所以我们现在在哪个阶段？

我帮你把路线压成这样：

**已经完成：**

`HUMAN UNKNOWN 核心命题`  
→ 人类的世界，只是世界的一种解释。

`产品本质`  
→ 探索 / 体验，不是使用，不是科普。

`世界池`  
→ 目前有 8 个候选方向。

**我们正在做：**

# 每个世界的「最小体验单元」

也就是：

**一个动作 → 一个巨大变化 → 一个明确感受。**

这一阶段做完，我们才应该挑 3 个。

因为现在单看设定挑，很可能会挑错。

---

我甚至建议把原来所谓的“90 秒体验线”再往前砍一步。

先别设计 90 秒。

## 先把每个世界的 **15 秒** 做出来。

如果一个文明在 15 秒内都没有任何东西让我：

> “诶？”

那它很可能不适合黑客松首发。

15 秒成立以后，再往外长：

**15 秒发现异常 → 30 秒摸到规律 → 60 秒第一次接触 → 想继续的人自己深入。**

这才符合你想要的那种**轻交互、重体验**。

我觉得我们现在下一步就该专门把这 8 个的 **「15 秒 killer moment」** 做透，然后很快就会看出来哪三个真的值得做。

## 12｜用户

我还是觉得太无聊了，纯让用户体验一下。改变一个东西之后，这个人就改变了，有什么意义呢？他想传达的世界观又是什么呢？我感觉并不觉得有什么好震撼的，甚至有一种“所以呢？你想干嘛呢？你想表达什么？”的感觉
我觉得这里面可以直接引导用户。比如唱首歌给他听，或者告诉他“你好，打个招呼吧”，和他分享一件什么事情。通过一个旁白或者引导助手，提示用户在引导下去感知、推进这个故事。

我觉得它更多地像是一个游戏，而不是一个浏览网站。这个游戏有不同篇章，就像不同的副本一样。而且它最终的目的，也是可以让我对我目前的世界有一些认知的更新和不同视角的转换。

比如说一个很快的世界，用户可能也会联想到：也许对于其他文明来说，我们的世界也是一个很快的世界。我某件事情经历了 3 个月，可能对他们来说也只是一瞬间；我心痛了 3 个月，我焦虑了 3 个月，可能对他们来说就是转瞬即逝。我觉得这些是最有价值的。摄像头的话，不一定。但是声音我觉得可玩的挺多的，比如大声或者小声、节奏，以及语音识别等等。或者就是让用户去模仿他们的交流方式，模仿他们的语言，去学习他们的语言。

但是你说的这几个世界，我仍然不觉得非常有吸引力。我不知道为什么，不知道是哪里走偏了，还不如你最开始提出的有吸引力。

我不知道要怎么办，不知道要问你什么问题好，才能把这个网站的股价定下来。

还有很重要的是鼠标的交互，比如鼠标移动的速度、移动的位置、点击、拖动。各种交互方式都可以和他们沟通。对，我觉得是一种沟通，用户的行为就是一种沟通，和这个文明的沟通。

## 12｜ChatGPT

对，我觉得我现在知道**哪里走偏了**。

后面几轮我们一直在问：

> 这个文明有什么新奇交互？

于是慢慢变成了“拖一下会怎样”“点一下会怎样”“环境会怎样回应”。

但这些只是**交互效果**。  
你真正感兴趣的从来不是“哇，这个按钮会变”。

你最开始吸引我的东西其实有三层同时存在：

**我真的去了另一个文明。**  
**我真的尝试和它建立了沟通。**  
**回来以后，我对自己原来那个世界产生了一点新的理解。**

少掉第三层，就会出现你现在说的：

> 所以呢？想表达什么？

---

# 我觉得 HUMAN UNKNOWN 的骨架现在应该重新定成这一句

## **去另一个文明生活几分钟，借一次它们的眼睛，再回来看看自己的世界。**

这比“体验一种奇怪的世界规则”准确得多。

而且我现在甚至不觉得它主要是“网站”。

它更像：

# 一个由不同文明组成的互动叙事游戏 / 数字体验作品

首页只是入口。

每一个 SIGNAL 都是一章、一个副本、一次接触。

---

# 而你刚刚说的这句话，可以直接成为核心设计原则

> **用户的行为，本身就是和文明的沟通。**

这个非常重要。

所以每个文明都不应该先问：

“用户点什么？”

而应该问：

# **这个文明认为什么叫“交流”？**

然后网页才决定用户怎么操作。

比如：

一个文明通过**节奏**交流。  
→ 鼠标点击节奏 / 声音节奏就是语言。

一个文明通过**距离**交流。  
→ 鼠标靠近和远离就是语言。

一个文明通过**停留时间**交流。  
→ 你注视多久就是一句话。

一个文明通过**组合**产生意义。  
→ 拖动、连接、分离就是语言。

一个文明通过**音量**理解意图。  
→ 你轻声、正常说、大声说，得到完全不同的回应。

一个文明没有“句子”，只有**运动轨迹**。  
→ 鼠标怎么画，就是你说了什么。

这样用户会慢慢意识到：

> **我连“怎么说话”都得重新学。**

这个比做十个炫酷动画强很多。

---

# 而且我非常赞成加入「引导者」

不是教程框。

不是：

> 第一步请点击按钮。

它应该是一个**接触辅助系统 / 翻译员 / 旁白**。

它只做一件事：

### 帮助一个人类第一次进入完全不同的交流体系。

比如刚进入：

> 「它好像注意到你了。」  
> 「试着和它打个招呼。」

就这一句。

用户可能自然说：

“你好。”

对方没反应。

旁白：

> 「它似乎不在意词义。再试一次，也许让它听见你的节奏。」

于是用户：

“你——好——”

世界产生变化。

这时候用户不是被科普。

她是在**学会接触**。

---

# 我觉得这才是你真正想要的「一层一层深入」

以前我们说：

捕获 → 靠近 → 进入 → 接触 → 深入

现在它终于有具体意义了。

### 捕获
我发现那里存在某种东西。

### 靠近
我开始看到它的世界和人类不一样。

### 进入
它的规则开始作用在我身上。

### 尝试沟通
我用人类的方法失败一次。

### 学会一点它的方法
我第一次真正收到回应。

### 交流
我可以把一点属于我的东西交给它。

### 回声
它用自己的世界观，把这件东西还给我。

最后这一步才是整个 HUMAN UNKNOWN 真正值钱的地方。

# 用你刚刚说的「极速文明」举例，现在它会完全不一样

之前：

> 看它们快速演化。

有意思，但不够。

现在：

## SIGNAL 071 / 极速文明

刚进去。

城市飞快发展。

10 秒就是几十年。

旁白：

> **「它们的一生，比你的一句话还短。」**

然后：

> **「告诉它们一件，在你看来持续了很久的事。」**

这里出现一次语音入口。

用户可能说：

> “我有一件事情已经焦虑三个月了。”

它不直接出现一个 AI 回答：

> “不要焦虑。”

那很烂。

而是用户说话的这 **4 秒钟**：

下面那个文明已经经历：

出生  
一代  
两代  
城市改变  
人离开  
植物长起来  
旧建筑消失

用户说完。

底下可能已经过去 240 年。

然后那个文明传来一句非常简单的翻译：

> **「三个月，是多久？」**

人类辅助系统可能显示：

> 对它们而言：约 0.003 个生命长度。

这时候用户自己就会产生你刚刚说的：

> 对啊。  
> 我痛苦了三个月，在另一种生命尺度里，它甚至连一下都算不上。

然后你甚至还能反转一次。

旁白：

> **「现在想象一下，也有一种文明，看着我们。」**

页面突然拉远。

刚才用户的一分钟体验，被放进一个更大的时间尺度。

人类城市也开始飞快出现、消失。

突然：

**我们也变成了极速文明。**

这个才是一个我觉得会记住的章节。

它有：

世界观  
视觉  
互动  
用户自己的输入  
认知回响

全部连起来了。

# 再看「无单数文明」，它也不能只是拖小球

现在我会这样写：

用户进去以后，看到几个生命正在组成一个存在。

旁白：

> **「它正在尝试认识你。」**

那个存在发出一个很鲜明的声音/形态。

然后旁白：

> **「和它分享一件你害怕失去的东西。」**

用户可以说一句：

> “我很怕一段关系结束。”

它听到了。

但没有回答。

其中两个身体离开。

那个“人”消失。

重新组成一个新的存在。

新存在拥有一部分旧记忆，但已经不是原来的它。

它可能传来：

> **「结束？」**

然后重新组合一次。

> **「你说的是，不再以原来的方式组成吗？」**

这时候这个文明的世界观才出来：

对人类来说：

关系结束  
= 某件东西没了。

对它们来说：

组合本来就是暂时的。

**组成过是真的。**

重新组合也是真的。

根本不存在“一个东西必须永远保持原样，才算没有失去”。

这时候拖拽才有意义。

它不是小游戏。

是这个文明用身体在回答用户。

我现在觉得这就比：

> “拖掉一个成员，它人格变了。”

强非常多。

# 所以现在世界应该这样设计

我建议我们以后每个文明都用一个非常简单的六格模板。

不是那些“它怎么繁殖、怎么记忆”的世界设定表。

就是：

| 问题 | 要回答什么 |
|---|---|
| **它相信什么？** | 这个文明最根本、最不同于人的世界观 |
| **它怎么沟通？** | 用户行为如何成为语言 |
| **它邀请用户做什么？** | 一个极简单的人类任务 |
| **它怎样回应？** | 必须只有这个文明才会给出的回应 |
| **哪一刻会让用户“啊”？** | Killer moment |
| **用户带什么回来？** | 它怎样让现实里的某件事看起来不一样 |

这才应该是第二阶段。

# 然后还有一个非常重要的变化

我们之前一直在找：

**“8 个不同的奇异世界。”**

现在我觉得标准应该改成：

# **8 种不同的世界解释。**

它们每一个都应该让人回来以后，获得一种不同的“观察位置”。

例如：

### 时间文明
带回来：

> **事情的长度取决于谁在计时。**

### 无单数文明
带回来：

> **改变并不一定意味着某个真实的东西消失了。**

### 活体世界
可能带回来：

> **你一直把自己当作环境中的独立个体，但也可以把自己理解为环境的一部分。**

### 多现实世界
可能带回来：

> **没选的道路不一定是在证明你选错了；“只有一个正确版本”本身就是一种世界假设。**

注意，这些不能直接作为鸡汤写给用户。

这是我们设计世界时心里知道的**认知回响**。

用户最好自己感受到 70%，最后只给 30% 的轻微翻译。

# 这也解释了为什么你觉得最早的版本更吸引人

最早我们说的是：

里面天然有一种：

**“我想知道它会怎么回答。”**

这是非常强的好奇心发动机。

后来我们为了避免 ChatGPT 套皮，把“问问题”几乎全部删掉。

结果把灵魂也一起删掉了。

现在应该把它找回来，但升级：

不是：

**一个外星 ChatGPT 回答问题。**

而是：

# **我把一件属于人的东西交给这个文明，它用整个文明来回答。**

有时候回答是语言。

有时候是一段时间。

有时候是组合。

有时候是环境变化。

有时候是声音。

这才是 HUMAN UNKNOWN。

## 所以我认为，我们现在最重要的事情已经不是“再调研八种文明”

也不是“继续画 UI”。

更不是“决定摄像头还是鼠标”。

现在应该先做：

# **8 个文明各自要把什么“世界解释”带回来？**

只要这一步没定，

再炫的交互都会有：

> 所以呢？

只要这一步定了，

我们才能反推：

**什么体验最适合传达它 → 什么沟通方式最自然 → 鼠标 / 声音 / 文字到底怎么用。**

我建议下一轮我们甚至**先不要坚持现在这 8 个**。

我重新从零帮你做一张：

### HUMAN UNKNOWN「世界观候选池」

每一个候选只写 4 件事：

**这个文明相信什么 / 它怎么看一个人类会关心的问题 / 用户怎么和它沟通 / 用户回来以后可能多了什么视角。**

做大概 12–15 个。

然后你只凭一个标准挑：

> **“这个世界我真的想进去待一下。”**

那时候剩下来的世界，我觉得才会真正是你的 HUMAN UNKNOWN。


## 13｜用户

## 13｜ChatGPT

对。现在我会非常明确地把它定义成：

# HUMAN UNKNOWN
**一款网页端沉浸式科幻探索游戏。**

我觉得这一下，整个东西终于有“游戏的骨架”了。

# 一、对，「引导者」就是游戏里的引导

但我不想做一个：

> “您好，我是 HUMAN UNKNOWN 新手助手，现在请点击左侧按钮。”

那会瞬间破坏世界。

它应该属于世界观本身。

我暂时叫它：

### CONTACT GUIDE / 接触引导系统

它可能没有形象，只有非常少的旁白。

它有三个职责。

**观察。**

> 「它注意到你了。」

**帮助试探。**

> 「它似乎没有在听你的词义。」  
> 「也许试试重复刚才的节奏。」

**翻译刚刚发生的东西。**

> 「第一次有效回应。」  
> 「它把你的声音理解成了靠近。」

所以它实际上同时承担：

**游戏教程 + 叙事旁白 + 翻译器。**

而且这正好解决你之前最大的 UI 问题。

我们不用摆：

说明书  
文明介绍  
数据卡  
规则页面  
教程弹窗

玩家需要知道的东西，**在事情发生的时候才出现一句。**

# 二、整个游戏的基本循环，现在可以定了

每一个文明其实都是一个 3～8 分钟左右的小副本。

不是一进去就：

> SIGNAL 071  
> 这是一个时间尺度文明……

而是：

### 0｜未知

HUMAN UNKNOWN 首页。

黑暗。

不同地方存在不同信号。

它们的**信号本身就已经带着世界性格**。

极速文明的信号一闪而过。

活体世界不是点，而是一块会轻微收缩的黑暗。

异质语言文明可能不断重复一个奇怪节奏。

多现实信号甚至会同时出现在两个位置。

玩家被什么吸引，就接近什么。

---

### 1｜捕获

玩家做一个极简单的动作把它抓住。

然后：

> **SIGNAL CAPTURED**

第一次没有告诉她这是哪一种文明。

---

### 2｜靠近

规则开始异常。

鼠标开始变。

声音开始变。

网页开始变。

引导者只提醒：

> 「这里的时间似乎不太对。」

而不是解释为什么。

---

### 3｜第一次接触

引导者给一个非常生活化的邀请。

不是：

> “请学习外星文明机制。”

可能是：

> **「跟它打个招呼吧。」**

或者：

> **「唱一点什么给它听。」**

或者：

> **「靠近它。」**

或者：

> **「留一样东西给它。」**

这一步非常重要。

因为用户从“看这个文明”变成：

# **我和它发生关系了。**

---

### 4｜人类方式失败

这个我现在觉得几乎每个文明都应该有一点。

不是让玩家受挫。

而是非常短暂地告诉她：

> 人类默认的交流方式，在这里不一定有效。

例如：

用户说：

“你好。”

没有反应。

旁白：

> 「它似乎没有在意你说了什么。」

用户继续发出声音。

旁白：

> 「等等。它好像在回应你的音量。」

于是玩家立刻懂：

**哦。我要换一种方式。**

---

### 5｜学会这个文明的一点规则

不用完全理解。

只需要获得一次：

> **“啊！我会和它说话了。”**

这是游戏性真正起来的地方。

---

### 6｜交换

然后才允许用户交出一点真正属于自己的东西。

一句话。

一个声音。

一个选择。

一段旋律。

一个动作。

甚至一个沉默。

文明拿到之后，**必须用它自己的世界观回应。**

这才是整关最核心的一幕。

---

### 7｜回声

玩家第一次获得：

> **这个文明怎么看人类刚才交给它的东西。**

不是心理咨询答案。

不是：

“你应该放下焦虑。”

而是一个陌生文明根本没有那种默认前提。

这就产生认知转换。

---

### 8｜离开

然后回到 HUMAN UNKNOWN。

玩家不是“完成任务 +100 XP”。

而是：

**UNKNOWN 少了一小块。**

# 三、你说的 HUMAN UNKNOWN → HUMAN KNOWN，我觉得非常漂亮

而且不要做普通进度条。

**标题本身就是进度。**

刚开始：

# HUMAN **UN**KNOWN

第一次真正完成接触之后。

`UN`

开始松动。

可能像信号一样脱离字面。

`UN` 慢慢漂走。

最后留下：

# HUMAN KNOWN

停两秒。

很安静。

玩家以为结束了。

然后远处突然又出现一个此前不存在的信号。

漂走的 `UN` 变成那个信号的一部分。

最后标题又轻轻恢复：

# HUMAN UNKNOWN

这比永远真的变成 HUMAN KNOWN 更好。

因为它表达的不是：

> “恭喜，你已经知道宇宙真相。”

而是：

> **你让一个未知变得稍微可知了一点。**
>
> **但认知的边界也因此向外推了一点。**

这个就是整个作品自己的哲学。

而且完全不用写出来。

一个动效就能表达。

# 四、所以我们以后设计文明，不再从「特效」开始

我们要从这个公式开始：

| 一个副本必须回答 | 例子：极速文明 |
|---|---|
| **它怎么看世界？** | 时间的长度不是绝对的 |
| **它怎么和人沟通？** | 你的几秒，是它几代人的历史 |
| **玩家第一次做什么？** | 看它 / 向它发送一个东西 |
| **玩家交出什么自己的东西？** | “一件在你看来持续了很久的事情” |
| **文明怎么回答？** | 在用户说话期间，它已经历几代；它甚至无法理解“三个月很久” |
| **玩家带回来什么？** | 我正在经历的长度，只是站在人类时间尺度上才这么长 |

所以：

### 世界观 → 游戏机制 → 玩家输入 → 文明回应 → 认知回声

是一条完整链。

少任何一段都会出现你刚才说的：

> “所以呢？”

我现在觉得这句话特别核心。

# 但你现在指出了一个更根本的问题：HUMAN UNKNOWN 到底 Unknown 什么？

我觉得这就是我们之前那几个世界让你觉得“和 HUMAN UNKNOWN 没那么相关”的原因。

我们一直在造：

> 一个奇怪文明。  
> 又一个奇怪文明。  
> 又一个奇怪文明。

可是名字已经承诺了一件更大的事情。

而是：

# **人类还没有活过的世界版本。**

或者再精确一点：

> **那些存在于人类默认认知之外，但仍然可能成立的世界解释。**

这和你的副标题正好扣死：

# HUMAN UNKNOWN  
### 人类的世界，只是世界的一种解释。

所以玩家真正探索的不是“Alien No.071”。

她探索的是：

> **如果时间不是我们理解的时间呢？**  
> **如果“我”根本不是一个稳定单位呢？**  
> **如果环境本身就是一个主体呢？**  
> **如果意义根本不用语言产生呢？**  
> **如果世界没有唯一版本呢？**

但是——这些问题**不展示给玩家看**。

这些是设计师后台的问题。

玩家只需要进去活几分钟。

## 我现在甚至会把 HUMAN UNKNOWN 分成三层意义

第一层是**世界的 Unknown**：

> 世界还能怎样存在？

第二层是**Human 的 Unknown**：

> 原来我一直以为理所当然的“时间、自我、语言、生命、现实”，只是人类的一套默认设置。

第三层才是最重要的：

> **当我暂时换了一套设置，我自己原来的生活突然有什么东西变得不一样了？**

所以极速文明才真正成立：

不是因为“他们活得很快，好酷”。

而是玩家回来以后突然产生：

> **“我所谓的三个月很漫长，也只是在我的时间尺度里很漫长。”**

这就是一个 Unknown 被短暂照亮。

标题重新变成：

# 所以 HUMAN UNKNOWN 的游戏骨架应该这样定

我们先不要纠结 8 个文明叫什么。

玩家身份其实已经非常清楚了：

### 你是一个进入 HUMAN UNKNOWN 的接触者。

首页是一片未知。

没有关卡菜单。

你寻找 SIGNAL。

被某一个吸引。

捕获。

进入。

这时**引导者出现**。

它不是普通游戏教程，更像 HUMAN UNKNOWN 的 **Contact Guide / 接触引导系统**。

它跟玩家一起搞不懂。

这一点非常重要。

不要让它像一个什么都知道的上帝：

> “欢迎来到某某文明，它们使用声波交流。”

很无聊。

应该是：

> 「它好像注意到你了。」

玩家：“你好。”

没反应。

> 「它似乎没在听你的词。」

玩家又尝试。

世界因为声音大小变化。

> 「等等……它可能在听你声音的形状。」

这时**引导者和玩家是共同探索者**。

它只能帮助玩家留意。

这一下就很有游戏感了。

然后每关实际上都在玩同一个大游戏：

但答案永远不同。

极速世界里，**时间可能就是沟通介质**。

语言世界里，**节奏是沟通**。

活体世界里，**距离和停留是沟通**。

另一个世界里，**鼠标轨迹可能就是一句话**。

再一个世界里，**组合与分离就是表达**。

所以用户第一次进入每关，其实都有一个非常诱人的问题：

我觉得这个比“8 个世界都给我体验一个哲学概念”好玩很多。

## 18｜ChatGPT

对，第一张和第四张的问题非常明显：**我把“它注意到你 / 它在看你”过度视觉化成了“眼睛”。** 这其实又掉回了人类默认——只要“观察”，就给它眼睛；只要“注意”，就给它凝视。和 HUMAN UNKNOWN 的方向是冲突的。

第三张也不是要做女性生殖器。我的原意是一个**未知结构正在裂开 / 接触通道正在形成**，想做成不像传统“传送门”的东西。但它现在明显会让人产生生殖器官联想，那就说明这个造型失败了。哪怕不是我的意图，只要视觉第一反应跑到这里，它就会把用户从世界里拽出来，应该直接废掉。

这四张我当时分别想表达的是：

- **第一张：**“第一次接触发生在你被某个东西注意到的瞬间。”我错误地把“注意”做成了眼睛。
- **第二张：**“你进入以后才发现整个场域都在回应你。”所以做成了网状、脉冲、鼠标附近出现回声。这个方向其实相对更对，因为**没有一个角色站出来**。
- **第三张：**“Unknown 不是按钮，是某种东西真的在你面前打开。”概念可以留，造型完全不要。
- **第四张：**想表达“观察你的不是一个个体，而是一整个分布式存在”。但又把“分布式观察”画成了很多眼球，所以还是太人类。

所以我现在觉得我们应该定一条很重要的视觉禁令：

# HUMAN UNKNOWN 尽量不把非人类能力翻译成人类器官。

观察 ≠ 眼睛。  
交流 ≠ 嘴。  
意识 ≠ 大脑神经元。  
生命 ≠ 血肉组织。  
入口 ≠ 门。  
文明 ≠ 城市。  
智能 ≠ 人形角色。

不然我们嘴上说“离开人类认知”，视觉上却一直在拿人类已有东西做隐喻。

真正有意思的应该是：**用户先感受到“某件事情正在发生”，再慢慢理解这可能就是那个文明的存在方式。**

比如首页直接开始接触，我现在会更倾向下面几种，不需要出现任何“生物长相”。

### 方向 A：整个空间开始朝你排列

一开始纯黑，只有极少的微粒。

鼠标动一下。

没有东西追着鼠标跑。

而是**远处很多原本毫无关系的东西，开始同时改变方向**。

你往左，它们不是往左移动，而是整个空间的排列关系改变。

停下来，又慢慢恢复。

Guide 只出现一句：

> 它好像不是在追踪你的位置。  
> 它在追踪你的变化。

这里已经发生 CONTACT，但我们根本没画“它”。

---

### 方向 B：它在你行动之前回应

这个我反而觉得很 HUMAN UNKNOWN。

鼠标准备靠近某处。

那个区域在你真正碰到之前，已经轻微变化。

第一次你可能觉得巧合。

第二次又发生。

Guide：

> 等等。  
> 它刚才是不是比你更早？

这一下直接把用户带进：

**“我和它共享的时间可能不是同一种时间。”**

没有星球、没有外星人、没有眼睛，但 Unknown 已经开始侵入网页规则。

---

### 方向 C：你碰这里，别处回答

鼠标在左边划一下。

左边没有反馈。

三秒以后，屏幕右下一个完全不相干的位置出现波纹。

再试一次。

又在别处回应。

慢慢发现两边存在某种规律。

Guide：

> 我们可能一直找错了“它在哪里”。

这个就开始把“一个东西应该待在一个位置”拆掉。

---

### 方向 D：声音把空间本身变成另一种东西

首页几乎完全黑。

Guide：

> 这里很安静。  
> 试着发出一点声音。

轻声说话。

不是出现声波图。

整个空间的距离感发生变化——远处的东西靠近，结构展开。

声音大一点，世界不是“变亮”，而是**空间拓扑改变**。

唱一个持续音，它可能稳定下来。

于是用户第一次就学到：

> 我的声音不是在“给它说话”，我的声音正在改变它所在的世界。

这个很适合你刚才说的声音交互。

---

我现在反而觉得 **04“意识之眼”真正值得保留的不是“眼”**，而是它给你的那种感觉：

> **我一打开页面，就已经站在某件事情里面了。**

没有 Banner。  
没有 Hero section。  
没有“点击开始探索”。  
没有一张漂亮宇宙宣传图。

**游戏已经开始。**

这一点是对的。

所以视觉下一轮我们应该追求的其实不是“外星感”，而是：

# 「规则异常感」

第一秒看起来几乎什么都没有。  
第二秒你动了一下。  
第三秒你发现：**这个网页不按人类熟悉的因果运行。**

这会比一个巨大眼球、外星森林、宇宙门都更接近 HUMAN UNKNOWN。

而且我现在会把首页定义成 **Layer 0：第一次发现“人类规则并不是唯一规则”**。它本身就是第一层游戏，而不是去往游戏的封面。

## 1. 项目名称与一句话

# HUMAN UNKNOWN

**人类的世界，只是世界的一种解释。**

当前最准确的定位：

> 一款网页端沉浸式科幻探索游戏。玩家以“人类”的身份，一层一层进入 HUMAN UNKNOWN。每深入一层，人类默认的某条认知规则都会开始失效；玩家不是读科普，而是通过鼠标、声音、时间、空间、关系等方式和未知发生真实接触，最后再回到人类世界，重新看自己。

项目已经从早期的“外星人 / UFO 数据网站”演化成了：

> **探索人类尚未活过、尚未真正体验过的世界解释。**

外星文明只是素材来源之一；硅基意识、植物智慧、群体意识、行星意识、多现实、不同时间尺度、维度世界等都可以成为 HUMAN UNKNOWN 的原料。

---

## 2. 最重要的核心命题

当前最重要的两句话：

1. **这个网页暂时接管了我理解世界的规则。**
2. **人类的世界，只是世界的一种解释。**

因此 HUMAN UNKNOWN 的目标不是：

- 给用户看很多科幻设定；
- 做 UFO / 外星人百科；
- 做“AI 外星人聊天”；
- 做一堆炫酷但彼此独立的小互动；
- 让用户自由挑“想去哪一个文明”。

而是：

> **设计一条完整、纵向、层层递进的认知旅程。**

---

## 3. UNKNOWN 的三层含义

这是目前整个项目最关键的结构性发现。

### 第一层：World Unknown

**世界还能怎样存在？**

玩家先接触“外部”的未知：不同沟通方式、生命形式、时间尺度、现实结构等。

### 第二层：Human Unknown

**那些我们以为理所当然的规则，其实只是“人类默认设置”。**

例如：

- 沟通一定依赖语言；
- 一个身体就是一个“我”；
- 环境只是背景；
- 一生有大致固定的时间尺度；
- 世界只有一个版本；
- 我们看到的就是完整现实。

### 第三层：My Unknown

**如果我暂时换了一套“世界设置”，我原来的生活会不会也出现另一种解释？**

这里不是心理咨询，也不直接告诉用户“正确答案”。用户经历完前面的世界以后，再回来看看自己的时间、关系、痛苦、选择、身份等。

这三层形成真正的纵深：

**世界的 Unknown → Human 的 Unknown → 我的 Unknown**

---

## 4. 最大的结构调整：从“横向选文明”改成“纵向深入”

早期方案：

> 首页有多个 SIGNAL / 多个文明，用户被哪个吸引就去哪一个。

用户后来明确否定了这个结构：

> “这个不是买菜。”

当前方向：

> **HUMAN UNKNOWN 是一条贯穿的线。玩家不选关卡，而是被游戏一层层带进去。虽然每一层遇到的世界不同，但每一层都比上一层更深入。**

因此早期“8 个世界”现在只是**世界素材池**，不再是 8 个并列关卡。

---

## 5. 当前 V0.1 纵向认知路线

这仍然是草案，不应直接冻结成代码，但目前最完整的纵轴是：

| 深度 | 玩家原本默认 | 这一层拆掉什么 | 可用世界素材 |
|---|---|---|---|
| 0｜HUMAN KNOWN | 我知道怎么使用网页、怎么判断因果 | 建立人类默认值 | 首页本身即第一次规则异常 |
| 1｜CONTACT UNKNOWN | 沟通就是“我说你听” | 什么叫接触 | 异质语言、声音/节奏、行为沟通 |
| 2｜LIFE UNKNOWN | 环境是背景，生命是其中的对象 | 谁才是生命 | 活海洋、植物、生态、行星意识 |
| 3｜SELF UNKNOWN | 一个身体就是一个“我” | 谁才是我 | 群体心智、共生、无单数文明 |
| 4｜TIME UNKNOWN | 我的“很久”就是很久 | 什么叫一生 / 时间尺度 | 极速 / 极慢文明 |
| 5｜REALITY UNKNOWN | 发生的世界就是唯一世界 | 什么叫完整现实 | 多现实、维度世界 |
| 6｜HUMAN UNKNOWN | 前面在研究“它们” | 把视角反过来观察人类 | 人类本身成为最后一个“文明” |
| 尾声｜MY UNKNOWN | 我已经有一套固定方式理解自己 | 把旅程带回自身 | 不直接给答案，只留下新的观察位置 |

关键原则：

> **每一层必须比上一层“更深”，且后面的理解要继承前面的学习，而不是每关重置。**

---

## 6. 世界之间要有“继承”，不能是小游戏合集

错误形式：

> 清空 → 新玩法 → 清空 → 新玩法。

正确形式：

- 第一层让玩家发现：**行为也可以是语言。**
- 第二层，玩家已经不会只等聊天框。
- 第三层，玩家已经能接受：**接触对象可能不是一个独立角色。**
- 更深处，玩家开始怀疑：**我看到的形式可能只是截面。**

同时 Contact Guide 也越来越少说话，形成自己的叙事弧。

---

## 7. Contact Guide / 接触引导系统

这是现在最重要的游戏机制之一。

它不是 FAQ、教程弹窗，也不是全知 AI。

角色定位：

> **游戏教程 + 叙事旁白 + 临时翻译器 + 与玩家共同探索的同行者。**

它应该“和玩家一起搞不懂”，而不是早就知道答案。

### Guide 的语言风格

短、即时、只在事情发生时出现。

例如：

> 「它好像注意到你了。」

> 「它似乎没有在听你的词。」

> 「等等……它可能在回应你的音量。」

> 「也许你一直找错了接触对象。」

> 「谁刚刚和你说话？」

> 「等等。」

到更深处甚至：

> **「我不知道该怎么翻译这个。」**

### Guide 的叙事弧

**导师 → 共同探索者 → 翻译失效 → 陪玩家面对未知。**

这可以成为游戏本身的一条隐藏情感线。

---

## 8. “接触”是整个游戏统一的大玩法

当前最核心的统一机制：

> **玩家要发现：在这一层世界里，什么才叫做“接触”？**

用户的行为本身就是沟通。

可能的输入：

- 鼠标位置；
- 鼠标速度；
- 鼠标轨迹；
- Hover / 靠近 / 远离；
- 停留时长；
- 点击；
- 点击节奏；
- 长按；
- 拖拽；
- 滚轮 / 缩放；
- 麦克风音量；
- 音调；
- 声音持续时间；
- 节奏；
- 语音识别内容；
- 沉默。

不建议黑客松首版依赖摄像头手势识别，主要因为浏览器权限、现场光线、识别稳定性和开发成本；当前优先级：

**鼠标 / 触摸 > 麦克风 > 摄像头。**

---

## 9. 交互设计的核心标准

早期曾提出：

> 一个世界 = 一条陌生规则 + 一个核心动作 + 一个不可忽略的变化。

后来又进一步修正，因为单纯“动作产生变化”仍然会出现“所以呢？”的问题。

当前完整链条应该是：

# 世界观 → 游戏机制 → 玩家输入 → 文明回应 → 认知回声

也可以用以下 6 个问题检查每一层：

1. **它相信什么？**
2. **它怎么沟通？**
3. **它邀请玩家做什么？**
4. **它怎样回应？**
5. **哪一刻会让玩家“啊”？**
6. **玩家带什么回来？**

最终不是为了炫交互，而是：

> **我把一件属于人的东西交给这个文明，它用整个文明来回答。**

有时候回答是一句话，有时候是一段时间、一次组合、环境变化、声音或空间结构。

---

## 10. 用户明确要求：未知不能等于纯困惑

重要原则：

# 未知 ≠ 看不懂

用户可以不知道这个世界的完整解释，但必须逐渐感知：

> **这里有自己的规则，而且我已经摸到了一点。**

因此不能靠“作者故意什么都不解释”制造神秘。

最理想的体验：

- 前几秒：发现异常；
- 很快：摸到规律；
- 接下来：真正和规律发生关系；
- 最后：理解并不完整，但体验已经成立。

---

## 11. 世界素材池（不是最终关卡）

对话过程中形成过以下主要世界素材。它们现在都不应被视为固定“8 关”，而是用于承载纵向认知路线的候选材料。

### 极速 / 时间尺度

核心：不同生命时间尺度完全不同。

人类作品：

- 《龙蛋》Dragon's Egg
- 《爱，死亡和机器人：冰河时代》Ice Age
- 《降临》Arrival（非线性时间为另一分支）

关键体验样例：用户说一句“我为这件事焦虑三个月了”的几秒里，下面的文明已经过去几十到几百年；最后镜头反转，人类也可能只是另一个观察者眼中的“极速文明”。

认知回响：

> **事情的长度取决于谁在计时。**

### 活着的世界 / 生命边界

核心：环境不是背景，环境本身就是主体 / 生命 / 文明。

人类作品：

- 《索拉里斯》Solaris
- Semiosis
- 《阿凡达》Avatar / Eywa
- Scavengers Reign

重点不是“环境会对鼠标发光”，而是玩家要逐渐发现：

> **我一直在找“谁在回应我”，但整个场域就是那个“谁”。**

### 无单数文明 / 自我边界

核心：多个身体临时组成一个“人”，组合变化，身份和记忆也变化。

人类作品：

- 《深渊上的火》A Fire Upon the Deep / Tines
- 《造星主》Star Maker
- Group Mind / Hive Mind 科幻传统

最有价值的世界观不是“拖走一个球，人格变了”，而是：

> **“我”可能并不是一个固定、连续、独立的单位。**

### 异质语言 / 接触方式

核心：意义不一定通过人类语言形成。

人类作品：

- 《使馆城》Embassytown
- 《降临》Arrival
- His Master's Voice
- 《巴别塔圣歌》Chants of Sennaar（游戏设计参考）

用户通过声音、节奏、形状、动作逐渐学会一点点“这里怎样产生意义”。

### 遗迹文明

核心：创造者已经不在，玩家只能通过遗物摸到局部规律。

人类作品：

- 《路边野餐》Roadside Picnic
- 《2001 太空漫游》
- Rendezvous with Rama

设计原则：

> **局部可理解，整体不可穷尽。**

### 多现实

核心：一次行为并不只产生一个唯一现实。

人类作品：

- 《彗星来的那一夜》Coherence
- 《瞬息全宇宙》Everything Everywhere All at Once
- 多世界 / Alternate realities 相关科幻

网页媒介本身可以分叉，玩家甚至看到“另一个自己”留下的幽灵轨迹。

### 尺度迁移

核心：人类尺度不是天然的观察位置。

人类作品 / 游戏：

- Everything（David OReilly）
- 《造星主》Star Maker

玩家可以从生物 → 生态 → 行星 → 星系，或者向内进入细胞 / 分子等。

### 维度世界

核心：我们看到的可能只是完整世界的切面。

人类作品：

- Flatland《平面国》
- 高维 / 维度科幻传统

经典例子：二维世界只能看到三维球体穿过时的点 / 圆 / 消失。

### 可复制意识（已降级为 Archive / 后续）

人类作品：

- Permutation City《排列之城》
- Pantheon《万神殿》
- Diaspora《散居》

概念：意识可以复制、暂停、产生多个版本。但当前体验容易与“多现实”撞，不适合黑客松首批优先。

### 后劳动 / 后稀缺文明（已降级）

人类作品：

- A Psalm for the Wild-Built《荒野机器人赞歌》
- Iain M. Banks 的 Culture 系列
- 《一无所有》The Dispossessed（相关文明价值讨论）

思想成立，但目前还没有找到足够强、足够独特的“可玩体验”，容易掉成“不要卷”的普通表达，因此不宜首发。

## 12. 一个曾经比较完整的“极速文明”体验样例

虽然未来纵向路线可能会重新排序，但这个样例很适合作为“世界观如何进入游戏机制”的参考。

1. 玩家进入，看见一团微小的光。
2. 放大，发现是一座城市。
3. 几秒后建筑变化。
4. Guide：
   > 「它刚刚过去了 43 年。」
5. 玩家看到一个生命出生、走过城市、消失。
6. Guide：
   > 「你认识它不到三秒。」
7. Guide 邀请：
   > 「跟它们分享一件，在你看来持续了很久的事。」
8. 麦克风开启，用户说出自己的内容。
9. 用户说话的几秒中，文明已经过去几十或上百年。
10. 文明可能问：
   > 「三个星期？」
   > 「那是什么尺度？」
11. 镜头突然拉远。
12. 地球 / 人类城市也开始快速建立、消失。
13. Guide：
   > 「也许也有人这样看我们。」

重点：不是告诉用户“人生很短”，而是**让用户实际经历一次尺度改变**。

## 13. 最终 HUMAN 回望的关键结构

当前很有潜力的最终反转：

前面玩家一直把自己当观察者，研究各种陌生文明。

最后没有新外星文明，画面出现普通人类城市 / 地铁 / 手机 / 工作 / 恋爱 / 焦虑。

Guide 用观察陌生文明的语气描述：

> 「这个文明以单个身体定义个体。」

> 「它们通常把时间分成过去、现在和未来。」

> 「它们会为了尚未发生的事件，提前产生长期的生理反应。」

玩家逐渐发现：

# 它在描述人类。

此时 Human 从观察者变成被观察对象。

最后的 My Unknown 不需要重做一关，可以只轻轻问：

> **「现在，再想一次最近困扰你很久的那件事。」**

不要求输入，也不告诉用户应该怎样理解。

## 14. HUMAN UNKNOWN / HUMAN KNOWN 的动态机制

用户提出：标题可以成为一种“进度条”。

当前较好的版本：

初始：

# HUMAN UNKNOWN

某一段真正从未知变为亲身经历后：

`UN` 开始松动、漂离，短暂出现：

# HUMAN KNOWN

随后 `UN` 并不真正消亡，它漂向更远处，未知边界再次扩张，最终重新回到：

# HUMAN UNKNOWN

表达的不是“恭喜你知道真相”，而是：

> **你让一小块未知变得可知，但知道得越多，未知也向外延伸。**

## 15. Human Archive 的位置

最开始的目标之一是聚合优秀科幻电影、小说、游戏、科学想象和真实目击 / UFO 资料。

现在已经明确：

> **这些内容不能放在首页，也不能抢体验。**

Human Archive 应该是体验后的“兔子洞”。

玩家经历某层之后，才有机会深入看到：

- 哪些小说曾经想象类似存在；
- 哪些电影 / 游戏做过类似探索；
- 相关科学假说；
- UFO / 民间记录；
- 艺术、神话等。

顺序：

**体验 → 好奇 → 档案 / 知识**

知识是探索后的奖励，而不是入口。

## 17. 视觉方向：目前已经明确的原则

最初多版视觉被否定的原因：

- 太像“宣传片 / Hero Page”；
- 太像“人类网站”；
- UI、数据、进度条、卡片太多；
- 把“注意 / 观察”画成眼球；
- 把未知入口画成门 / 裂隙；
- 过度使用人类器官和熟悉隐喻。

当前核心视觉原则：

# 首页不是封面，游戏在打开页面时已经开始。

没有：

- Banner；
- Hero Section；
- “点击开始探索”；
- 八个文明入口；
- 传统导航菜单；
- Dashboard；
- 大量说明文字。

应该追求：

# 规则异常感

第一秒：几乎什么都没有。  
第二秒：玩家动一下。  
第三秒：发现——**这个网页不按人类熟悉的因果运行。**

### 视觉禁令

# HUMAN UNKNOWN 尽量不把非人类能力翻译成人类器官。

- 观察 ≠ 眼睛
- 交流 ≠ 嘴
- 意识 ≠ 大脑 / 神经元
- 生命 ≠ 血肉组织
- 入口 ≠ 门
- 文明 ≠ 城市
- 智能 ≠ 人形角色

视觉目标不是“外星感”，而是让玩家感觉：

> **某件事情正在发生，但它不按我熟悉的规则发生。**

## 18. 首页 Layer 0 的几种规则异常方向

这些是当前文字讨论里比“画一个外星生物”更符合 HUMAN UNKNOWN 的方向：

### A｜整个空间朝玩家重新排列

鼠标移动时，不是物体跟着鼠标，而是整个空间的排列关系变化。

Guide：

> 「它好像不是在追踪你的位置。」
> 「它在追踪你的变化。」

### B｜页面在用户行动之前回应

玩家还没有真正靠近，目标区域已经提前变化。

Guide：

> 「等等。」
> 「它刚才是不是比你更早？」

直接引入“人类因果 / 时间规则可能不是唯一规则”。

### C｜你碰这里，别处回答

玩家在左侧操作，几秒后右下角出现回应；不断试验以后发现稳定关联。

Guide：

> 「我们可能一直找错了‘它在哪里’。」

拆掉“一个东西应该待在一个位置”的默认。

### D｜声音改变空间结构

玩家发声以后，空间拓扑 / 距离 /结构本身变化，而不是传统声波可视化。

Guide：

> 「这里很安静。」
> 「试着发出一点声音。」

玩家逐渐发现：声音不是“话”，声音是一种改变世界的物理行为。

## 19. 当前阶段：不要正式冻结代码骨架

这个结论在最后一次结构调整后又变化了。

曾经建议可以先做 Vertical Slice：

> 首页 → SIGNAL 071 极速文明 → Human Known 动效 → 返回首页。

但用户随后提出了关键结构调整：

> **HUMAN UNKNOWN 不应该是让玩家从多个文明中自由选择，而应该是一条纵向、层层深入的线。**

因此当前最新结论是：

# 暂时不要把正式游戏骨架 Ding / Coding 下来。

原因：如果现在 Coding，会把还没想透的横向结构冻结在实现里，之后反而被已有代码绑架。

### 现在可以交给 Coding Agent 的只有“技术 Spike”

这些与世界观结构无关，以后无论骨架怎样调整都可复用：

- 鼠标距离驱动粒子 / 场域变化；
- 鼠标速度 / 轨迹监听；
- 麦克风音量 / 节奏分析；
- 语音识别实验；
- 网页多现实 / 分叉视觉；
- 时间加速场景；
- Guide 旁白淡入 / 淡出；
- 全屏沉浸音效；
- 无 UI 状态切换；
- HUMAN UNKNOWN 字体中 `UN` 的解体 / 漂移 / 恢复动画。

正式 Coding 之前要先完成：

> **HUMAN UNKNOWN 的认知下降路线 / 纵向叙事架构。**

## 20. Coding Agent 未来正式 Handoff 应包含什么

不要只给参考图。

参考图只能回答“长什么样”，Agent 真正需要的是“什么时候发生什么”。

正式交接需要至少包含：

1. **项目定位**
2. **核心命题**
3. **完整状态流 / 章节流**
4. **每层玩家的输入方式**
5. **每层世界的反馈规则**
6. **Contact Guide 全部文案与触发条件**
7. **声音 / 鼠标 / 时间 /空间的交互规则**
8. **视觉参考**
9. **禁止事项**
10. **完成标准 / Demo 验收标准**

### 当前已确认的禁止事项

- 不要 Dashboard
- 不要数据卡
- 不要传统网页 Hero
- 不要“请选择文明”
- 不要 ChatGPT 聊天框作为主体
- 不要大段世界观科普
- 不要解释过度
- 不要纯迷惑
- 不要用战争 / 征服 / 黑暗森林作为核心想象力
- 不要把外星 / 非人类默认做成人形、眼睛、大脑、嘴等
- 不要用复杂操作掩盖体验不成立

## 21. 目前最重要的设计问题（下一步）

现在真正需要解决的已经不是：

- “选哪 8 个世界？”
- “画哪张 UI？”
- “用鼠标还是声音？”
- “Coding Agent 用什么技术？”

而是：

# HUMAN UNKNOWN 的纵向认知路线到底是什么？

需要继续回答：

2. **为什么必须按这个顺序？**
3. **每一层为什么比上一层更深？**
4. **前一层学到的东西怎样成为后一层的前提？**
5. **Contact Guide 怎样随着深入逐渐失效？**
6. **最后 Human 被反过来观察的瞬间，怎样与整条旅程形成闭环？**
7. **最终 My Unknown 到底留给玩家怎样的余味，而不变成心理测试 / 鸡汤？**
8. **首页 Layer 0 的第一次“规则异常”到底用什么方式实现，才能从第一秒就进入游戏？**

这是正式编码前最应该继续打磨的内容。
