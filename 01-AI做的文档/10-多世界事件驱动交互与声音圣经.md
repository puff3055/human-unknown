# HUMAN UNKNOWN 多世界事件驱动交互与声音圣经

> 版本：V1.0（预制作基线）  
> 分支：`codex/world-architecture`  
> 适用范围：从首页交接后的世界侧体验；首页只定义接口，不在本分支修改  
> 核心链路：**世界观 → 世界规则 → 玩家输入 → 文明回应 → 认知回声**

---

## 0. 已锁定的产品决定

1. 这是一段由玩家行为推进的互动旅程，不是按秒播放的电影，也不是把视频切成几个可点击片段。
2. 首次旅程固定经过三个世界：**截面之外 → 交换场 → 仍在发生**。第一次不显示世界选择菜单；完成后才开放回访。
3. 每个世界只证明一个反直觉规则。玩家必须亲手制造证据，叙事才继续。
4. 状态转换只能由可验证的输入与世界响应触发。时间只用于插值、消抖、可访问性辅助和声画包络，不能让剧情自动前进。
5. 引导者不是全知旁白，而是一个会误判、会修正措辞的翻译器。它与玩家一起失去旧解释。
6. 世界不是背景，文明也不是 NPC。空间、材料、交换关系和遗留路径本身就是文明。
7. 视觉锚点用于统一材质、构图和三态变化，不作为静态全屏影片替代实时交互。
8. 音频默认关闭，必须由用户明确动作开启。麦克风只可作为「交换场」的可选输入；不录音、不转写、不上传、不保存。
9. 体验结束不是“通关结算”，而是把玩家的发现连接到现实中的数学、科学争论与科幻作品。
10. 首页保持只读。世界侧必须能在没有任何首页数据时独立启动。

## 1. 产品命题

### 1.1 用户最终应带走什么

HUMAN UNKNOWN 不试图证明“宇宙真的如此”，而是让用户短暂失去三种习以为常的确定性：

- **我看见的就是对象本身**；
- **文明由一个个独立个体组成**；
- **没有被我选择的可能性已经消失**。

三个世界依次拆解这三条直觉，并在终点给出同一个回声：

> 未知不一定在远方。它也可能一直与我们重叠，只是我们的感官、尺度与叙事方式无法完整读取它。

### 1.2 体验承诺

- 进入后 1 个动作内，世界必须对输入作出可感知但不讨好的反应。
- 每个世界都包含一次“我以为”和一次“原来不是”。
- 用户不需要读说明书；规则通过因果关系被发现。
- 没有失败弹窗、分数、血条、任务清单或传统胜利动画。
- 用户可以停留、试错、回退、静止；系统不会在他没有理解时自行剪到下一幕。

## 2. 整体叙事架构

```text
首页的注视与接近
        ↓ 用户主动进入
奇点交接：熟悉坐标被压缩
        ↓ 玩家使空间重新获得方向
截面之外：看见的形状不等于完整生命
        ↓ 同一脉冲穿过断裂截面
交换场：个体不一定是文明的基本单位
        ↓ 玩家停止局部拯救，整体开始回应
仍在发生：未选择不等于不存在
        ↓ 当前路径与遗留路径共同完成结构
未知档案：把体验连接到现实知识与作品
        ↓
回访世界 / 回到现实继续阅读
```

### 2.1 五个阶段

| 阶段 | 用户感受 | 主要交互 | 允许离开的条件 |
|---|---|---|---|
| 奇点交接 | 被首页中的未知吸入，而非跳转页面 | 按压、拖拽、放松，使压缩场重新形成方向 | 玩家主动稳定出第一条空间轴 |
| 截面之外 | 封闭规则被不可能的穿越打破 | 改变截面、追踪断裂形态、留下轨迹 | 玩家证明多个断面属于同一连续存在 |
| 交换场 | 局部帮助造成远处代价 | 注入、撤回、扩散、可选声息输入 | 玩家改变策略后，整体网络自主重平衡 |
| 仍在发生 | 当前路径不是唯一有效现实 | 选择、放弃、重返、与遗留轨迹对齐 | 当前与一条旧路径共同显露连续结构 |
| 未知档案 | 体验被命名，但没有被解释完 | 探索自己的行为回声与来源谱系 | 用户自由回访或离开，不设自动结束 |

### 2.2 首次与回访

- **首次旅程**：固定顺序，无世界地图，不提前展示三章标题。世界之间通过同一物质状态连续转译。
- **完成后回访**：档案中出现三条“未知谱系”，可直接重返任一世界。回访不是关卡选择，而是沿自己的发现轨迹逆行。
- **会话恢复**：只保存已显露的世界、无障碍和声音偏好；不保存麦克风数据，不生成性格标签。

## 3. 事件驱动系统

### 3.1 总状态机

```text
BOOT
 └─ entry.intent ─→ SINGULARITY
      └─ axis.coherent ─→ W1_SECTION
           └─ being.continuity_proven ─→ SEAM_1
                └─ exchange.field_reachable ─→ W2_EXCHANGE
                     └─ field.system_reply ─→ SEAM_2
                          └─ reality.membrane_reachable ─→ W3_REALITIES
                               └─ reality.echo_cooperation ─→ FINAL_SEAM
                                    └─ archive.intent ─→ ARCHIVE
                                         ├─ revisit.world ─→ W1 / W2 / W3
                                         └─ exit.intent ─→ external / home
```

`SEAM_1` 和 `SEAM_2` 是短暂的材质转译状态，不是定时过场。玩家仍可移动并影响转译方向；只有下一世界的核心规则已经在画面里可操作时才完成切换。

### 3.2 统一输入词汇

系统将鼠标、触控、笔、键盘与可选声音统一为语义事件。世界逻辑不直接依赖某一种硬件。

| 语义输入 | 鼠标 / 触控笔 | 触屏 | 键盘替代 | 用途 |
|---|---|---|---|---|
| `probe` 探测 | 移动 / 悬停 | 单指移动 | 方向键 | 改变观察位置，不承诺改变世界 |
| `contact` 接触 | 按下并移动 | 按住并移动 | 按住 Space + 方向键；或用 Enter 切换接触状态 | 对世界施加连续影响 |
| `release` 放开 | 抬起 | 离开屏幕 | 松开 Space | 让系统显露自身动力 |
| `trace` 留痕 | 有曲率的连续轨迹 | 单指轨迹 | 方向键路径 | 给高维生命与多现实世界留下可复用记忆 |
| `revisit` 重返 | 接近旧痕迹并沿其方向运动 | 同左 | Tab 选择痕迹后 Space | 让已放弃状态重新参与 |
| `voice-envelope` 声息 | 可选麦克风包络 | 可选麦克风包络 | Space 脉冲 | 只改变交换的扩散方式 |

采样特征包括：归一化位置、速度、加速度、曲率、方向反转、静止、接触压力（设备支持时）、覆盖区域、轨迹重访程度和释放后的系统响应。不得采集语义化语音内容。

### 3.3 进度不是时间，而是证据

每个世界维护一组 0–1 的不可见“证据变量”。它们不是给玩家看的进度条，而是用来判断玩家是否亲手见过核心因果。

通用规则：

- 单次快速乱划不能直接完成世界；证据必须来自至少两类相互关联的事件。
- 证据升高时，世界先改变，再由引导者反应。旁白不能先告诉答案。
- 长时间无输入只触发低强度的“可供性提示”，绝不增加叙事证据。
- 可供性提示响应玩家上一次动作，例如让最后触碰处轻微回声；不出现箭头、手势教程或倒计时。
- 用户重复无效动作时，系统扩大因果反馈，而不是降低门槛后自动通关。
- 用户可以主动在无障碍面板开启“明确提示”；提示只描述动作，不揭示世界观结论。

### 3.4 事件契约（实现命名）

| 事件 | 最低载荷 | 说明 |
|---|---|---|
| `entry.intent` | `pointerType`, `position`, `seed` | 用户主动进入世界侧 |
| `axis.coherent` | `direction`, `confidence` | 奇点场因用户输入形成稳定方向 |
| `slice.boundary_crossed` | `sliceDepth`, `entityPhase` | 封闭边界出现不可能穿越 |
| `being.continuity_proven` | `segments`, `coherence` | 多个断面被证明是同一存在 |
| `exchange.field_reachable` | `seamDirection`, `seed` | 第一条材质接缝已转译为可操作交换场 |
| `field.perturbed` | `location`, `energy`, `spread` | 玩家向交换场注入扰动 |
| `field.remote_cost_seen` | `source`, `remoteRegion`, `delta` | 局部增益与远端代价建立因果 |
| `field.system_reply` | `restraint`, `globalCoherence` | 玩家改变策略，网络自主回应 |
| `reality.membrane_reachable` | `seamDirection`, `retainedFlows` | 交换流已转译为可操作概率膜与当前路径 |
| `reality.abandoned` | `traceId`, `geometry` | 一条未完成路径成为遗留现实 |
| `reality.echo_joined` | `traceId`, `junction` | 遗留路径与当前路径对齐 |
| `reality.echo_cooperation` | `traces`, `seamCoherence` | 两个现实共同完成结构 |
| `archive.intent` | `journeyEvidence` | 玩家主动接近最终回声，而非自动结算 |

## 4. 奇点交接：从首页被吸入

### 4.1 叙事功能

首页已经让用户感觉“某个活体在看我”。世界侧接手时，不重新做一段品牌片头，而是让这个接近动作产生物理后果：屏幕坐标、光、声音与鼠标残影被同一点压缩，随后由玩家亲手重新建立方向。

### 4.2 互动过程

1. 页面加载时保持首页末态的深黑与残余中心，不显示章节标题。
2. 用户第一次移动，残余场向其运动方向发生非对称偏折；世界明确知道他从哪里来。
3. 用户按下后，指针不是按钮，而是成为压缩中心。运动越一致，散乱粒子越形成一条空间轴。
4. 用户放开时，系统测试这条轴是否足以承载空间。若尚不一致，场会松开并保留他制造的偏向；若已一致，轴展开成「截面之外」的第一条切面。

这里的“稳定”由方向一致性、覆盖和释放后的存续共同判断，不以“按住 N 秒”为剧情条件。

### 4.3 引导语

- 初始：`不要急着辨认它。先让这里有一个方向。`
- 反复快速乱划：`速度只会把入口压得更薄。`
- 轴形成后：`好。我们暂时把这个方向叫作“里面”。`

最后一句刻意埋下错误前提；第一世界会推翻“里面/外面”的绝对性。

### 4.4 首页交接契约（只定义，不修改首页）

世界侧优先尝试读取 `sessionStorage['humanUnknownHandoff:v1']`：

```json
{
  "version": 1,
  "source": "home",
  "seed": 248731,
  "inputType": "mouse",
  "approach": {
    "x": 0.52,
    "y": 0.47,
    "speed": 0.18,
    "stillness": 0.64,
    "disturbance": 0.31,
    "directionX": -0.18,
    "directionY": 0.42
  },
  "preferences": {
    "reducedMotion": false,
    "sound": "unknown"
  }
}
```

- 所有字段都可缺省；数据异常时静默回落到本地种子与默认入口。
- `seed` 只改变构图和路径初态，不决定内容或难度。
- 世界侧不会反向要求首页暴露内部实现，也不会在本分支编辑首页文件。

## 5. 世界一：截面之外

### 5.1 世界命题

> 你看到的连续变化，可能只是一个更完整存在与感知平面的交集。

这是数学截面概念的科幻转译，不宣称现实中已发现高维生命。

### 5.2 世界规则

- 屏幕不是照相机，而是一张可以改变位置与方向的“感知截面”。
- 同一高维存在穿过不同截面时，会呈现为彼此分离、形态变化甚至穿过封闭边界的局部形状。
- 存在不会服从鼠标；鼠标只改变玩家能看到它的哪一部分。
- 玩家留下的运动轨迹最终会成为这个存在回应玩家的另一张截面。

### 5.3 三态与转换条件

#### W1-A 封闭空间异常

对应锚点：`截面之外/01-封闭空间异常.png`

- **初态**：多个黑玻璃腔体看似彼此封闭；局部银白截面在腔体中出现和消失。
- **玩家动作**：移动改变截面深度；接触拖动改变截面倾角。
- **规则证据**：同一相位脉冲在没有开口的两个腔体中先后出现；玩家主动跨过边界至少一次。
- **世界反馈**：边界不破碎，脉冲却在另一侧继续。这样证明发生的不是“撞破墙”。

引导者先误判：`它被困在这些空腔里。`

异常出现后修正：`不——被边界分开的，可能只是我们。`

#### W1-B 生物断层与连续脉冲

对应锚点：`截面之外/02-生物断层与连续脉冲.png`

- **初态**：三个相隔的断面以同一节律发生形变，但外观不完全相同。
- **玩家动作**：改变切面，使至少两个断面在相位上重合；快速扫过只会制造噪声，连贯探索会提高 `continuity`。
- **规则证据**：玩家观察到“形态不同、脉冲连续、边界无开口”同时成立。
- **世界反馈**：断面之间不绘制解释线；它们通过同一压力波、声相位与材质应力自行显露关联。

引导语：`别追形状。追它们共同改变的那一刻。`

#### W1-C 玩家轨迹显露身体

对应锚点：`截面之外/03-玩家轨迹显露身体.png`

- **初态**：玩家过去的曲线路径留在空间中，成为一条新的观察截面。
- **玩家动作**：重访自己轨迹的一部分，同时改变截面倾角；系统把多个断面沿轨迹短暂拼成一个无法被单视角容纳的身体暗示。
- **完成证据**：至少三个断面参与、相位连续、玩家轨迹与存在的自主运动发生一次交叉后仍保持连续。
- **文明回应**：存在不展示完整肖像，而是沿玩家遗留轨迹“看回去”，并把其中一段改写为通往下一世界的交换脉络。

引导语：`我们没有看见它的全貌。它借我们的路线，看见了我们。`

### 5.4 无失败恢复

- 一直高速乱划：切面增厚、细节减少，最近一次相位连续的区域变得更亮，暗示降低速度但不暂停体验。
- 只在小范围徘徊：存在会自主把一个相关断面带到该范围边缘，扩大可发现区域。
- 长时间静止：脉冲继续自主运行，证明生命不依赖玩家；剧情证据不增加。

### 5.5 声音映射

- 截面深度 → 共振峰高度，不映射为简单音量。
- 同一存在的各断面共享一个极低频相位；空间位置不同，但脉冲相位连续。
- 玩家把断面错误地当成多个个体时，声音仍先泄露“它们是一个”。
- 完成时不播放胜利和弦；原本分散的泛音只在玩家路径交叉处短暂成为一个不可定位的音色。

## 6. 世界二：交换场

### 6.1 世界命题

> 文明的边界不一定围住个体；它也可能存在于交换本身。

灵感来自共生体、微生物群落、真菌网络、黏菌运输网络与社会性昆虫的组织研究，但不把任何现实系统夸大为已知的统一意识或非人类文明。

### 6.2 世界规则

- 没有可选中的居民。半透明矿物膜、孔隙、压力波和资源流共同构成文明。
- 玩家接触某处会增加局部可用能量，但同一交换网络的远处会承担稀薄、降温或连接断裂的代价。
- “停止干预”不是唯一正确答案；关键是从局部最大化转为感知整体的流动与恢复能力。
- 网络会主动利用玩家造成的扰动，最后给出不等同于服从的整体回应。

### 6.3 三态与转换条件

#### W2-A 自主交换场

对应锚点：`交换场/01-自主交换场.png`

- **初态**：多层膜独立交换，压力前沿缓慢穿过整个体积；无指针标记、无中心节点。
- **玩家动作**：先探测；悬停只改变可见度，不向系统注入资源。
- **规则证据**：用户观察到至少一次无玩家参与的远距离转移，建立“它本来就在运作”。

引导语：`我找不到个体。也许这里还没有居民。`

#### W2-B 玩家注入与远端失衡

对应锚点：`交换场/02-玩家注入与远端失衡.png`

- **玩家动作**：接触某处或用 Space 注入；压力/移动节律改变注入形态。可选声息输入只控制扩散宽度和脉冲间隔。
- **规则证据**：局部变亮与远端稀薄形成可追踪的同一压力前沿；用户移动到远端后仍能看见源头残留。
- **世界反馈**：没有红色警告或“资源 -10”。远端材料变薄、孔隙打开、声音谱线缺失，构成代价。

引导者误判：`它在向你索取。再给它一点。`

远端失衡后修正：`我把明亮当成了需要。`

#### W2-C 整体重平衡与文明回应

对应锚点：`交换场/03-整体重平衡与文明回应.png`

- **玩家动作**：改变先前策略，例如放开局部、用更宽的慢轨迹分散输入、在稀薄区域与富集区域之间建立低强度联系。
- **完成证据**：系统记录到“看见远端代价 → 改变行为 → 全局连通性恢复”的因果链，而非要求数值完美平衡。
- **文明回应**：网络吸收玩家最后一次扰动，形成一股不再以玩家为中心的宽压力前沿；它经过全部层后，把其中几条流保留为下一世界的现实轨迹。

引导语：`这里没有谁拥有资源。交换本身，正在决定谁暂时存在。`

### 6.4 可选声音输入

- 首次主动点开“用声息触碰”时才请求麦克风权限。
- 只在本机实时计算音量包络、持续/间断节律和粗略频谱重心；不做语音识别、说话人识别、录音、上传或持久化。
- 大声不等于更强。系统对输入做限幅和归一化，鼓励节律与留白，避免用户误以为需要喊叫。
- 拒绝权限、没有安全上下文或没有麦克风时，Space 脉冲具有完整等价功能。
- 关闭入口始终可见且可由键盘操作；离开世界立刻停止媒体轨道。

### 6.5 无失败恢复

- 持续向同一点注入：局部逐渐饱和，对新输入变得迟钝；远端反馈扩大，帮助用户理解代价。
- 完全不接触：自主交换继续，并在用户上次探测处附近暴露一条可影响的薄膜。
- 试图逐点“修好”所有暗区：网络会让远处再次变化，揭示它不是打地鼠式维修游戏。

### 6.6 声音映射

- 每层膜有窄带噪声而非固定音符；交换改变频谱密度。
- 局部注入先产生接触声，远端代价随后以空间反向的谱线缺口出现。
- 全局重平衡时，声音不是变得更大，而是从多个孤立声源变为连续、可绕过玩家的声场。
- 所有声音变化都有膜厚、孔隙和压力前沿的视觉等价物。

## 7. 世界三：仍在发生

### 7.1 世界命题

> 没有成为“现在”的路径，不一定被删除；它可能以另一种关系继续影响可见现实。

这是多现实的体验隐喻。它受到 Everett 相对态与多世界讨论启发，但不宣称多世界诠释已经被实验单独验证，也不把量子世界、宇宙学多宇宙和哲学可能世界混为一谈。

### 7.2 世界规则

- 用户每次形成明确方向后再反转或离开，会留下一条低亮度的“遗留现实”。
- 遗留路径不是录像回放：它保留当时的动作倾向，并在之后自主继续一小段。
- 当前路径永远最暖、最清晰，但不是能力最强的路径。
- 某些结构需要来自不同深度、不同历史的两条压力前沿互补才能显露。

### 7.3 三态与转换条件

#### W3-A 唯一现实表象

对应锚点：`仍在发生/01-唯一现实表象.png`

- **初态**：只有当前暖银路径与玩家光标明确可见；黑玻璃概率膜中仅有很弱的未点亮压痕。
- **玩家动作**：探索并至少一次放弃未完成路径。系统不提示“请选择 A/B”。
- **规则证据**：路径离开后没有消失，而是以材质应力留在膜中。

引导语：`这里只有你走过的这一条。其余只是没有发生。`

#### W3-B 多条现实显现

对应锚点：`仍在发生/02-多条现实显现.png`

- **玩家动作**：再次改变方向或靠近旧压痕；不同深度的遗留轨迹开始显影并自行延伸。
- **规则证据**：至少三条路径在同一连续空间中彼此遮挡、穿过不同膜层，同时保留各自的旧动作倾向。
- **世界反馈**：不使用分屏、时间树或故障特效；差异通过深度、材质冷暖与遮挡表达。

引导者修正：`我说“没有发生”，只是因为这里没有把它算作现在。`

#### W3-C 遗留现实共同完成

对应锚点：`仍在发生/03-遗留现实共同完成.png`

- **初态**：当前暖路径到达潜在大结构，但单独施力只形成一个停滞的半截压力前沿。
- **玩家动作**：重访一条来自不同深度的冷银旧路径，在它原有方向上给予一次接触，然后回到当前路径的互补交点。
- **完成证据**：当前路径与旧路径的方向、相位和交点同时对齐；不是简单碰撞，也不是收集三把钥匙。
- **文明回应**：两个前沿共同展开跨越多层概率膜的连续表面。其他遗留路径仍在，不因“正确答案”而被删除。

引导语：`不是另一个你来救你。是被我们丢下的关系，仍有能力完成这里。`

### 7.4 无失败恢复

- 用户从不改变方向：当前路径最终会在大结构前自然停滞，附近膜层通过微弱冷痕提示曾经可离开的方向。
- 制造大量杂乱路径：只保留行为差异显著的少数轨迹，其余合并为材质应力，避免画面与运算爆炸。
- 用户找不到互补路径：停滞前沿会与最相关旧路径共享一次微弱相位脉冲，但不绘制连接线。

### 7.5 声音映射

- 当前现实是近场、温暖、清晰的单声源；遗留现实是不同深度与方位的短暂反射，不做俗套回声台词。
- 当前路径单独停滞时，声音保持未解决的频谱缺口，不用失败音。
- 旧路径加入后，两个不完整频谱互补成更宽声场；其他路径仍留下可听但不抢占注意力的余量。
- 非耳机环境下，深度仍由滤波与混响长度表达；视觉因果完整保留。

## 8. 引导者：会犯错的翻译器

### 8.1 说话规则

- 先描述可观察现象，再给暂定解释。
- 每个世界最多一次明确误判和一次修正；不能变成插科打诨的角色。
- 玩家正在操作时不连续播报；文字在世界边缘生成并随世界材质消退，不用字幕框。
- 新句子由证据事件触发，不由进入后经过多少秒触发。
- 同一个句子被打断后不强制重播；用户可在无障碍面板查看文本记录。
- 不说“做得好”“完成任务”“下一关”“你选择了正确答案”。

### 8.2 语气弧线

| 阶段 | 语气 | 认知位置 |
|---|---|---|
| 奇点 | 克制、操作性 | 相信空间可被重新命名 |
| 截面之外 | 第一次失去把握 | 承认感官边界 |
| 交换场 | 从观察者变成参与者 | 承认干预改变研究对象 |
| 仍在发生 | 不再抢先解释 | 承认单一叙事的局限 |
| 档案 | 提供来源而非结论 | 把判断权交还用户 |

## 9. 声音系统

### 9.1 四层结构

1. **自主底层**：世界在没有玩家时仍运行的低密度声场。
2. **接触层**：输入立即产生的局部触觉声，保证操作可感知。
3. **规则证据层**：远端代价、相位连续、遗留现实加入等核心因果的声音证明。
4. **留白层**：当玩家需要观察关系时主动削减频谱；沉默也是反馈，不是资源未加载。

不制作从头到尾固定时长的配乐。所有层根据世界状态与输入实时混合；可以使用短素材、卷积响应和合成器，但不能让音乐时间线主导叙事。

### 9.2 开启与控制

- 第一次有意按压入口时显示一句：`允许这个世界发出声音`；确认动作同时创建或恢复 `AudioContext`。
- 拒绝或忽略后体验完整继续，不重复弹窗追问。
- 提供可聚焦的静音按钮、音量调节和“减少突发声”选项；设置跨会话保存。
- 页面失焦时平滑降低声音；离开页面时停止麦克风轨道并释放音频资源。
- 建议母线保留充足动态余量，限制峰值；禁止惊吓式爆音、持续低频压迫和把耳机作为必要条件。

### 9.3 技术原则

- 使用 Web Audio 参数平滑，避免每帧直接跳变造成 zipper noise。
- 空间声用 `PannerNode` 或等价双声道模型；关键信息不能只依赖左右声道定位。
- `AnalyserNode` 只处理本地即时特征，不连接任何网络上报。
- 音频解锁必须来自用户手势；不得尝试绕过浏览器自动播放策略。

## 10. 可访问性与输入降级

### 10.1 减少动态效果

当 `prefers-reduced-motion: reduce` 或用户主动开启时：

- 取消大幅吸入、镜头推拉、强视差和高速粒子穿越。
- 用局部透明度、边缘应力、色温和静态前后遮挡表达同一因果。
- 状态条件、可探索范围和叙事内容不缩水。
- 不用突然闪白；任何周期闪烁都远低于危险频率，并优先完全避免。

### 10.2 键盘与触控

- Tab 能到达声音、提示、退出与档案入口；焦点样式清楚但与世界材质一致。
- 方向键移动探针；按住 Space 接触、松开 Space 结束接触；也可用 Enter 切换接触状态；Esc 聚焦最小设置；M 切换声音。
- 触控不依赖 hover；所有 hover 反馈都可通过首次轻触获得。
- 不使用 Pointer Lock。拖拽期间只做局部 Pointer Capture，抬起、取消或失焦时立即释放。

### 10.3 多通道等价

- 所有关键声音证据都有可见的材质或空间变化。
- 所有关键颜色差异同时使用厚度、运动方式、纹理密度或轮廓区别。
- 引导语有可回看文本；不强制语音旁白。
- 麦克风永远不是通关条件。

### 10.4 渲染降级

- 首选 WebGL / GPU 实时场；上下文丢失或性能不足时切换 Canvas 2D。
- 降级版保留输入—远端响应—认知回声三层因果；可减少粒子数和体积感，但不能退化成静态图片轮播。
- 页面不可见时暂停高成本绘制；恢复时从语义状态重建，不依赖错过的时间片。

## 11. 结束段：未知档案

### 11.1 不是结算页

三世界完成后，跨膜表面逐渐成为一座可探索的“来源谱系”。页面不显示分数、人格判断或“你的类型”。它只透明地回放三类可观察行为：

- 你在哪一刻停止追逐形状，转而追踪连续关系；
- 你如何从局部注入转为观察整体代价；
- 哪一条被你放弃的轨迹最后重新参与。

文案统一使用“这次旅程显露了……”而不是“你是一个……的人”。用户可以关闭行为回声，直接看来源。

### 11.2 内容分层

每条来源必须标注一种认识论身份：

- **数学模型**：可严格定义的几何关系；
- **科学观察**：现实系统中的可重复现象；
- **科学争论 / 解释**：证据允许但尚有竞争观点；
- **科幻设定 / 艺术启发**：用于拓展想象，不冒充事实。

来源以连续谱系排布，不做电商式卡片瀑布流。用户靠近某条谱系时，先看到“它和刚才哪种感受有关”，再决定是否展开摘要或外链。

### 11.3 首批推荐谱系

#### 截面之外

- **《Flatland / 平面国》— Edwin A. Abbott**（科幻 / 数学寓言）：感知维度如何限制对存在的理解。
- **Slicing Polyhedra — Brown University**（数学模型）：平面与三维对象、三维超平面与四维对象相交时，观察者得到变化的截面序列。
- **Miegakure — Marc ten Bosch**（互动作品）：通过移动与旋转三维截面探索四维空间；同时明确把高维存在与现实实证区分开。

#### 交换场

- **《Children of Time / 时间之子》— Adrian Tchaikovsky**（科幻）：从不同感知、生态与行为机制推导非人类文明，而不是给人类社会换外形。
- **《Solaris / 索拉里斯星》— Stanisław Lem**（科幻）：面对无法被人类交流框架完整翻译的他者。
- **Holobiont / hologenome 正反论文**（科学争论）：把宿主与微生物作为复合实体的框架，及其关于伙伴忠诚度、冲突与选择单位的批评。
- **Superorganism 研究**（科学讨论）：某些真社会性昆虫群体呈现群体层组织整合，但这不等于已证明单一人格或蜂巢心灵。

#### 仍在发生

- **Hugh Everett, “Relative State” Formulation of Quantum Mechanics**（物理理论史）：多世界讨论的重要起点。
- **Stanford Encyclopedia of Philosophy: Many-Worlds Interpretation**（科学解释综述）：区分形式主义、经验对应与“世界”概念，并说明当前不存在简单的独占性验证。
- **《The Garden of Forking Paths / 小径分岔的花园》— Jorge Luis Borges**（文学）：并存可能性如何改变因果叙事。
- **《Anxiety Is the Dizziness of Freedom / 焦虑是自由引起的眩晕》— Ted Chiang**（科幻）：人与近邻平行可能性的伦理关系。

### 11.4 科学边界文案

档案必须明确：

- 数学上可描述高维截面，不等于现实中已发现高维生命。
- 共生网络、黏菌运输或社会性昆虫可以提供组织类比，不等于现实中已发现统一的非人类文明意识。
- 量子实验支持量子理论的预测，不等于已经排他性证明 Everett 多世界本体。
- “多世界诠释”“宇宙学多宇宙”和“哲学可能世界”不能混称。

## 12. 视觉与素材实施规范

### 12.1 共同视觉语法

- 近黑负空间；材料主要为黑玻璃、云母、矿物膜、银白衍射与极少量暖铜能量。
- 光只证明结构、压力与因果，不用作霓虹装饰。
- 世界之间共享材料家族，但改变组织逻辑：截面 → 网络 → 概率膜。
- 禁止：HUD、卡片、关卡地图、圆形传送门、能量爆炸、故障风、赛博霓虹、眼睛意象、人物立绘、传统星空背景。
- 指针可成为世界内的小型物质现象，但不能永远是一枚系统光标贴纸。

### 12.2 锚点用途

| 世界 | 状态 1 | 状态 2 | 状态 3 | 运行时重建重点 |
|---|---|---|---|---|
| 截面之外 | 封闭空间异常 | 生物断层与连续脉冲 | 玩家轨迹显露身体 | 切面、相位、腔体、轨迹采样 |
| 交换场 | 自主交换场 | 玩家注入与远端失衡 | 整体重平衡与文明回应 | 连续膜、扩散、远端耦合、压力前沿 |
| 仍在发生 | 唯一现实表象 | 多条现实显现 | 遗留现实共同完成 | 路径记忆、深度遮挡、互补交点、跨膜接缝 |

九张图的路径、预览与生成说明见 `00-项目参考材料/世界架构视觉锚点/README.md`。

### 12.3 素材策略

#### 必须实时生成

- 指针影响、轨迹、切面移动、场扩散、远端代价、路径遗留与状态转译；
- 对用户输入有因果意义的全部光、材质应力和声音；
- 移动端 / 减少动态效果版本的等价反馈。

#### 可预制

- 低频噪声纹理、法线 / 位移底图、极短的颗粒与膜摩擦声、空间脉冲响应；
- WebGL 初始化前或上下文恢复时的低对比静态占位；
- 档案中的原创抽象谱系符号。

#### 不应提前批量生成

- 所有“最终画面帧”、长配乐、带固定节拍的过场、九张锚点的简单变体海洋；
- 未确定交互槽位的装饰素材；
- 受版权保护的作品封面。档案采用书名、作者、原创符号和外链。

### 12.4 下一轮素材槽位

只有在实时灰盒证明需求后再制作：

1. 三套 1024–2048 px 无缝低频材质（腔体 / 矿物膜 / 概率膜）；
2. 两套低分辨率蓝噪声与粒子 sprite；
3. 6–10 个低响度接触 one-shot；
4. 3 个可循环的无旋律世界底层；
5. 1 个短卷积响应族，用于“同一相位、不同空间”的声学证明；
6. 档案的 8–12 个原创谱系符号。

若程序噪声与 Web Audio 合成已达到质感，不为“素材齐全”而额外生产文件。

## 14. 验收标准

### 14.1 叙事与因果

- 页面空置不会自动跨越任何世界状态。
- 每个世界的完成日志能列出“玩家输入 → 文明响应 → 引导者修正”三类事件。
- 不读引导语的测试者仍能指出至少一个局部行为造成的远端或延迟结果。
- 第一次旅程不会被误认成三张概念图轮播、影片或关卡菜单。

### 14.2 交互

- 指针 / 触控首次输入的可见响应目标为一帧内开始，重计算不阻塞主线程。
- 任意世界可以通过鼠标、触控或仅键盘完成。
- 麦克风关闭、拒绝或不可用不会阻断「交换场」。
- 页面失焦、`pointercancel`、WebGL 上下文丢失后不会锁死输入。

### 14.3 可访问性

- 减少动态效果模式完整保留三条核心因果链。
- 声音关闭时所有规则证据仍可见；颜色感知受限时仍有形态 / 纹理差异。
- 交互控件具备可访问名称、可见焦点和足够点击区域。
- 没有强制自动播放声音、危险闪烁或无法停止的动态内容。

### 14.4 性能与恢复

- 根据设备能力分档粒子与膜层密度；语义状态不随画质档变化。
- 目标桌面 60 fps、常见移动设备 30 fps 以上；出现持续掉帧时自动降低成本。
- 状态恢复使用事件证据快照，不依赖重放固定时长动画。

### 14.5 分支边界

- 所有实现提交位于 `codex/world-architecture`。
- 首页实现文件在本分支的 diff 中保持不变。
- 关键阶段均有已推送的 Git 提交，可按阶段回退。
