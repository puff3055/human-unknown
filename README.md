# HUMAN UNKNOWN

> **人类的世界，只是世界的一种解释。**

HUMAN UNKNOWN 是一个探索不同生命形态与文明形态的沉浸式交互科幻网站。它不是资料展示页：观众会进入世界，以移动、触碰、停留、声音或其他简单行为与其中的存在发生一次真正的接触。

## 当前一句话

当前汇合候选已经贯通 V4.5.3 首页“第一次接触”和第一章植物／群体智能单页实时网络：未知生命在首页注视并回应用户，中央凝视后由同一个光点把她带入植物整体的局部感知。后续世界仍作为独立候选开发，尚未接入这条主旅程；它们的具体顺序、故事和玩法以最新产品决定与原型验收为准。
