# HUMAN UNKNOWN

> **人类的世界，只是世界的一种解释。**

HUMAN UNKNOWN 是一个探索不同生命形态与文明形态的沉浸式交互科幻网站。它不是资料展示页：观众会进入世界，以移动、触碰、停留、声音或其他简单行为与其中的存在发生一次真正的接触。

1. [产品说明](01-AI做的文档/12-HUMAN_UNKNOWN_PRODUCT_BRIEF.md)：我们为什么做、什么已经确定、什么仍是当前方案。
2. [当前项目状态](PROJECT_STATUS.md)：现在做到哪里、正在做什么、应从哪个版本开始。
3. [产品决策与更新记录](01-AI做的文档/13-产品决策与更新记录.md)：新方向替代了哪些旧结论。
4. [Agent 协作规则](AGENTS.md)：阅读顺序、状态判断、文档维护和版本规则。
5. [版本管理、确认与文档同步规则](01-AI做的文档/04-版本管理与改动确认规则.md)：准备修改时使用的确认、验收和回滚流程。

然后再根据具体任务，从 [AI 文档索引](01-AI做的文档/README.md) 中选择相关规格。不需要默认阅读所有历史文档。

## 当前一句话

当前黑客松候选已经贯通完整桌面旅程：**序章“第一次接触” → 第一章“THE GREEN BODY／群体生命” → 第二章“RECURSIVE COSMOS／递归宇宙” → 第三章“EYE MULTIVERSE／多重宇宙”**。三个世界保持独立渲染，通过同向纵深载体完成跨页衔接；声音偏好在页面之间继承，环境不持续制造噪声，声音主要由用户操作触发。
